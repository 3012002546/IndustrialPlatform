# PF05 移动端分层聊天与系统管理员流程

## 用户确认范围及实现

- PDA/Mobile 聊天入口只显示会话列表，选择后进入现有终端 conversation 详情路由。详情不占用列表空间，提供固定可见、48px 高的返回会话按钮；返回列表保留筛选与草稿。列表页不标记隐藏聊天的消息已读；详情浮层不会留在列表页。
- 管理员范围为平台内置 SYSTEM_ADMIN。协作四页不弹出密码再认证框，而是静默创建服务端命令上下文并申请短时操作凭据。Identity 从当前持久化 AuthenticatedUser.IsSystemAdmin 判断是否免密码，继续检查用户状态、锁定、会话安全版本、签名 binding 的租户/actor/session/action/request/scope/hash 和有效期。普通用户缺密码仍返回 403；前端角色改动不能取得凭据。
- 系统管理员本人新申请的导出直接 Queued，服务端记录本人授权、时间，Audit 标注 administratorAuthorized。后台允许这种本人授权记录直接执行，不套用普通双人审批的等待过期规则，仍检查冻结消息范围和版本、执行期限、文件状态、下载授权。
- 管理员旧的本人 PendingApproval 导出显示“生成导出”，可显式启动；普通用户自批仍为 403。没有在打开列表时执行旧任务。非管理员及法律保全的独立审批流程保留。
- 主方案 §11.2/§11.7、数据与页面规格、前置契约补充同步记录用户的新规则。无数据库结构或已应用迁移变更。
