## E1：平台查询与动态 CMP

- 在独立 SQLite 上启动真实 Kestrel HTTP 服务，正常初始化管理员、登录、创建/发布 Query 报表、授权并查询。四份报表为合成 Constant 数据，分别返回 12、2、0、201 行。保留正常身份、权限及报表执行器；测试宿主用内存撤销存储替代 Redis 会话撤销，不能据此声称真实 Redis 故障与撤销链已经验收。
- 12→2→0 刷新与重新查询通过，12 行实际量合计为 1254。第二账号与同账号第二页分别编辑为 777/888，第一页刷新不改变它们。未登录返回 401，无功能权限返回 403；只有运行授权而没有设计授权时，设计资源按现有合同返回 404，运行投影读取成功。
- 页面通过运行投影读取绑定，不再要求设计文档权限。提供目录翻页和八字段显式映射；查询上限 200 行、响应上限 2 MiB、请求超时 30 秒。201 行拒绝替换旧结果，不静默截断。接口模拟另外覆盖字段映射、取消和超量；延迟模板及取消解析验证旧结果不能回写新代次。
- CMP 保留原文件，动态验证 12/200/2/0 行（原六行回归也通过）。Table 区域、逐行公式、汇总引用、验证和条件格式随填充范围更新，缩行与空结果无旧尾行。普通查询不创建服务端工作簿或上传编辑快照。

证据：`evidence/platform-real.json`、`platform-real.xlsx`、`contract-20261116.log`、`template-independent.json`、`lifecycle-extra.json`。宿主 `host/` 及其隔离数据库均仅用于本机实验。

| 样本 | 本轮核对内容 |
| --- | --- |
| 参数配置（合成） | 前导零长编号、高精度文本、数值/布尔/null/零、以等号开头的普通文本、日期、富文本分段、数字格式、边框及数据验证 |

| 跨表生产（合成） | 三张工作表、跨表公式、共享公式展开、编辑后重算，595/-5/1190 的缓存结果，隐藏列、冻结及仅有格式的空表 |
| 现有 CMP | 动态 Table/公式区域、原六行和扩缩行、公式模式与结果值模式、清空后的无残留输出 |

输出先结束正在编辑的单元格，等待当前代次计算，再捕获独立快照。公式模式与结果值模式分开。缺少计算结果或常见公式错误时明确拒绝输出；删除单元格后不会从原模板恢复旧值。支持值/空白/比较/AND/OR/通配符筛选；非 A 列起始的筛选列号与隐藏行单独验证。

ExcelJS 输出经 openpyxl 独立解析。四份代表文件已由本机 Microsoft Excel COM 正常打开、全量重算、另存并导出 PDF；另存后的长编号、日期、数值和跨表结果再次独立回读通过。Excel 的 `RepairMode` 属性不可读取，自动化关闭提示，因此仅记录“正常打开/重算/另存”，不记录“人工确认无修复提示”。未验证 WPS。

浏览器打印基于全部当前快照和可见行，支持多表分页；修正了 `0.00` 被打印成一位小数及日期显示问题。检验记录浏览器 PDF 为 4 页、Excel PDF 为 2 页；基础内容完整不代表精确分页一致。浏览器暂未完整映射模板的纸张、重复多行表头、富文本分段样式和条件格式视觉，实体打印机未验证。

明确拒绝通用导入的 Table（CMP 专用入口除外）、命名区域、图片/图表/透视/外链/宏对象；拒绝颜色筛选输出及增删/改名工作表后的模板输出。验证和条件格式沿原 XLSX 保留，未作为浏览器可编辑规则实现。其它复杂或未覆盖的样式、默认样式、公式语义、结构编辑和不可信 ZIP 的资源保护仍需产品化前补齐，不承诺无损通用往返。

证据：`verify-templates.mjs`、`verify-template-files.py`、`verify-excel.ps1`、`verify-office-output.py`；输出在 `evidence/templates/`，汇总在 `template-results.json`、`excel-verification.json`、`excel-independent.json`。

## E3：容量与生命周期

固定本机 Edge 157.0.4341.60、Node 24.18.0、1440×1000，使用 Vite 正式构建预览。`capacity-20261116.json` 记录构建入口 SHA-256、自然堆和显式 GC 后堆、DOM、监听器，以及导出期间约 50 ms 间隔采样。显式 GC 仅用于区分留存，不能代替正常用户运行的峰值。

已测：500 次 6/2/0 刷新，40 次关闭/重开，60 次编辑并撤销到历史边界，1000/10000 行构建与计算，万行 XLSX 导出，12 次 CMP 下载/打印，三页面并存及关闭/重载。断言和浏览器异常检查通过。300→500 次刷新，GC 后 DOM 均为 875，监听器不随代次增长；仍有正常堆增长，不承诺无限刷新占用恒定。

最终入口 SHA-256：`3508d8b73ad48a0a666d5ead27831c4124b3287cce27d5ccb37f2660671f0a5f`。1000/10000 行构建并等待计算分别为 1051/3722 ms；万行导出期间采样 JS 堆峰值 148214900 字节（约 141.3 MiB，不含全部浏览器进程/RSS）；300→500 次刷新 GC 后堆增加 1393316 字节。关闭后约 39 MB、重载后约 24 MB；这些是该环境单轮测量，不作为 SLA。

当前实验限额：平台查询 200 行/2 MiB/30 秒；样例最多 10000 行；导入压缩文件 10 MiB、10 张工作表、总使用区域 200000 格，每表最多 10020 行/100 列。这是本机实验边界，标准机、复杂公式、真实数据、多个用户服务端并发和完整浏览器/RSS峰值尚未验收。主包约 8.15 MB（gzip 2.23 MB），仍有拆包及主线程序列化成本。
