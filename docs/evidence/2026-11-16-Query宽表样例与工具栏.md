## 数据集字段筛选（不要求预定义参数）

- 配置页直接多选数据集字段作为查询条件。保存字段 ID 与类型；显示名称跟随字段标题，重复同步保留有效筛选字段并更新类型，已移除字段的条件同步清理。兼容旧参数筛选；有既存必填数据集输入时保留其输入控件。
- 文本为不区分大小写的包含匹配，数值为最小／最大值（可单边留空），日期为包含起止当天的区间，布尔为是／否。数值输入以字符串传递，避免前端转换丢失大数、小数精度。多个条件按 AND 组合。
- 后端只接受已发布报表配置中的字段，拒绝未知／重复字段、非法值和反向区间。基于原字段绑定先过滤完整授权来源结果，再投影、计数、排序与分页；允许配置隐藏字段作为条件。
- 查询与服务端后台导出共用筛选解释器。筛选条件存入原有运行访问快照，无数据库迁移；重试沿用原条件。无字段筛选的旧 operation hash 保持兼容；有筛选的请求将条件纳入幂等校验。
