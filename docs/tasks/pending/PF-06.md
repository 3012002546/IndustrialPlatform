禁止默认扩展：新程序集/信令服务/会议首页/房间管理、JoinTicket/ParticipantGrant/EngineLease、多引擎、第三人、同时双屏、远控、摄像头/系统声音、录音录像、外部MES/原生包。不要为此范围添加通用媒体平台框架。

特别按规格执行：

- 初次仅Low端add三个transceiver，High映射远端槽，避免双方各建一套重复m-line。
- Accept后立即Bind并确认，授权弹窗等待仍计入Setup60秒；任何await后核验generation。
- End不靠expectedVersion拦住清理；EndAll按具体旧ID幂等，不能误结束新通话。
- 语音slot两行与Call/Outbox在同一事务；失败先rollback再查冲突，不能仅用进程锁保证跨角色忙线。
- 状态事件可到用户组，SDP/ICE只能到本次选定ConnectionId；认证sid/ver/exp按双方检查。
- 系统Audit actor为空且原事件时刻不变；中央审计失败不等待它才能停媒体。
- 通用媒体连接失败会影响两种能力；只新增设备/授权失败应保留原能力，不虚构完全网络隔离。

## 验收和证据格式

停止必须先有真实活动源及增长计数，再触发结束。正常≤5s，静默失联为最后有效确认请求发出＋30s且最多5s调度容差，截止后再观察10s。按音频/视频MID/SSRC分别观测；页面黑屏、关闭页面、WSS断开、票据或TURN凭据到期、PC总字节均不能独立判定通过。旧媒体止住的同时，保留能力必须连续。

源码变更后从仓库根fresh Release build，再相关测试、solution Release --no-build测试；前端typecheck/lint/test:unit/build及必要媒体E2E，完整命令在规格§8.4。构建锁/环境失败单列，释放本次资源后重新build，不能用旧二进制宣称新代码通过。
