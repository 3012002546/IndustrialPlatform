## 2. 前置与首版范围

顺序为 PF-06A 客户端专项 → 原 PF-07～PF-10A → **PF-10B 标签平台** → PF-11 IoTCollector → MES 业务。此为执行排期；Label 不依赖 OperationsCenter/IoTCollector/MES 领域表，首个外部项目可用标准 DTO 提供业务数据。

首版拥有独立运行、三类默认/自定义模板、PDF/图片底稿、ZPL 指令、契约/映射/快照、任务/明细/历史/重打、Windows 工位 Agent、PDA 原生蓝牙直连、真实项目接入和恢复试点。不包括全品牌、全数据库、通用规则引擎、完整离线业务或称量判定。

## 3. 宿主与架构

Browser/Electron/PDA → Label.Service 的可信 API → 数据准备/模板渲染 → 任务与 Outbox → 被授权 Agent/终端领取 → 持久执行/设备 → 回执/历史。

核心 Host 为 Label.Service；内部 Template、DataPreparation、Rendering、PrintJob/History 只按所有权分模块，暂不拆渲染服务/设备注册服务。Agent 主动连服务，浏览器不自由访问本地设备；Electron 复用本机 Agent。先通过平台公开契约完成身份/权限、菜单/页面、文件、持久审计与初始化的真实兼容链，再用同一核心验证外部MES宿主适配及无宿主最小装配；规则见蓝图32§2.1～2.2。禁止复制平台账号/文件/审计体系，也不能跨库读Identity/MasterData/OperationalData/File/Audit表。

## 5. 初始化与通用约束

ServiceKey/InitializationUnitKey=`label`；LogicalDatabaseName=`label_db`；PostgreSQL Schema=`label`，模块表前缀 template_/data_/print_。一个服务级 migration/seed 双账本和 Outbox，实际消费者才加 Inbox；技术记录不机械继承 Entity。领域对象沿用模板的 NId/生命周期/并发字段；同聚合普通 ParentId 外键，跨模块/服务只存稳定 NId 和快照，不建跨域外键。

平台由 SystemData 编排同一服务初始化器；独立模式本地受控维护入口调用 Inspect/Plan/Apply/Verify，运行 Ready 只依赖本地 ledger/必要种子/可信配置。服务不持管理员凭据自行建库，不向控制面传 SQL/Secret，不使用 EnsureCreated。Standard/Advanced 服从环境，独立发布同样执行版本/锁/checksum/备份恢复规则。

SystemBaseline 提供权限/策略目录；TenantBaseline 提供三类可复制示例；EnvironmentSample 仅显式 Development/Test；独立管理员 SecretBootstrap 只声明需求，由安全引导注入，禁止默认通用密码。时间使用 DateTimeOffset/timestamptz、UTC RFC3339；金额/数量不用浮点，按字段精度/舍入与单位处理。

## 6. 核心模型与事务

| 对象 | 业务字段/约束 |
| --- | --- |
| LabelCategory/TemplateRevision | NId、CategoryNId、Revision、State、尺寸/单位、字段绑定、渲染格式；发布后不可变 |
| DataContractRevision/BindingRevision | 字段类型/权威来源/人工权限/敏感级别、映射/客户规则/版本，唯一匹配 |
| PreparedJob | NId、SourceSystemNId、BusinessRef、模板/契约/绑定/CustomerMappingRevisionNId、RenderProfileSnapshot/Hash、InputHash、SnapshotHash、ArtifactHash、ExpiresOn；不可悄悄重取数或换打印配置 |
| PrintJob/PrintItem | NId、PreparedJobNId、业务明细标识、Copies、目标打印机/工位、状态；不同容器独立明细 |
| PrintAttempt | Job/ItemNId、ExecutionNId/Epoch、执行节点、提交时间、确认来源、结果/错误、原重打关联；追加记录 |
| Printer/ExecutorBinding | 设备标识、连接类型、协议/驱动、型号/DPI、绑定节点/权限、支持回执层级；凭据仅 Secret 引用 |

实体字段仅列业务内容，通用生命周期按模板；快照/产物不可变，清理按引用/保留/保全策略，不以普通软删除重新激活旧打印任务。幂等记录键为可信 TenantNId+调用主体/来源+RequestNId，保存请求指纹；同键异载荷返回 409。

准备/正式提交/领取/回执各在本地数据库事务内维护事实与 Outbox；设备 I/O 不纳入数据库事务。调度租约不保证物理 exactly-once。PrintAttempt 在设备提交前持久写意图、之后写回执；提交不明必须 OutcomeUnknown，人工核实并受权处理。状态与恢复规则完整继承蓝图 35 §6。

## 7. API 与外部数据契约

平台外部 `/label/api/v1/**`，内部 `/api/v1/**`，独立部署由反代保持相同公开语义；平台信封 ApiResult/TraceId，二进制产物下载不强包 JSON。

| Method / 资源 | 用途与授权 |
| --- | --- |
| GET/POST `/templates`、POST `/templates/{nId}/revisions` | 模板读取/草稿管理，label.template.read/manage |
| POST `/templates/{nId}/revisions/{revision}/publish` | 发布不可变版本，label.template.publish + 并发版本 |
| GET/POST `/data-contracts`、`/bindings` | 字段与映射版本，label.data.manage |
| POST `/prepared-jobs` | 输入来源/业务标识或标准字段/版本/明细及renderPrinterNId，服务端固定DPI/介质/格式配置；label.print.prepare；RequestNId 幂等 |
| GET `/prepared-jobs/{nId}`、`/prepared-jobs/{nId}/preview` | 受权快照/预览，屏蔽不允许下发字段 |
| POST `/print-jobs` | PreparedJobNId+snapshotHash+目标/份数，label.print.submit；再次校验权限/有效期/来源状态及目标渲染配置兼容性 |
| GET `/print-jobs`、`/print-jobs/{nId}` | 历史/逐明细/确认来源，label.history.read |
| POST `/print-jobs/{nId}/cancel`、`/print-jobs/{nId}/reprints` | 取消/原快照重打，独立权限与原因 |
| GET/POST `/printers`、`/executors` | 设备绑定与状态，label.device.manage |
| POST `/executions/claim`、`/executions/{nId}/receipts` | 绑定节点服务身份、epoch、幂等回执；不是普通用户权限 |

外部数据契约显式版本化；受控取数只接受注册来源和业务标识，不接受任意 URL/SQL。认证不是目录读取，默认单一主要来源；本地与外部同名不自动合并。订单取消和来源版本校验用消费方端口，在 001 固定实际接口；客户不提供撤销信号时登记时效限制，不能宣称即时联动。

事件采用 Label.PrintJobPrepared.v1、Submitted.v1、ItemStatusChanged.v1、ReprintRequested.v1 等受控契约，携带 EventNId、TenantNId、业务 NId、版本、OccurredOn/TraceId，不带敏感原文/凭据。Outbox 至少一次、消费者幂等；独立模式本地 Dispatcher/数据库领取，不为形式依赖 RabbitMQ。

## 8. 页面与多端流程

PC：分类/模板列表→草稿设计→绑定字段→预览→发布；数据源/契约/映射分开配置；打印机页显示连接方式、协议、节点与已验回执能力；历史主表/明细展示每条状态、确认来源、重打关系与安全错误。

作业流程：平台业务入口/外部受控上下文/独立录入导入→选择授权打印配置→准备→核对固定预览/明细/份数→确认兼容目标→提交→查看进度。三模式使用同一核心页面与契约，平台真实菜单/权限/主题先验；过期或来源变化要求重新准备。“结果未知”提供核实入口，不能出现默认一键自动重试。“重打原标签”与“用最新数据重新生成”分开操作并授权。

PDA：列表→扫描/选择→预览确认→本机蓝牙或固定工位→逐条结果；支持软键盘、48px 触控、断连和返回恢复。Mobile Web 至少查看授权历史/状态，生产打印仅展示已验证容器能力。管理页复用黄金页，设计器画布不强套表格；支持中英、主题/密度、键盘、空/加载/错误/无权限/冲突状态。

## 9. 安全、错误与运维

错误映射：字段/类型/来源非法 400；无权限 403；不可见资源 404；版本/幂等/业务已变更 409；准备过期 410；设备/数据源暂不可用 503；任务 OutcomeUnknown 作为业务状态返回，不能伪造成功或按普通 5xx 自动重发。

受控渲染、指令转义、秘密客户字段最小下发、产物/日志/缓存/诊断脱敏、节点认证与能力白名单按蓝图 35 §7。指标包括队列年龄、结果未知数、提交/确认延迟、离线节点、错误类别，不用业务名称/标签内容做高基数指标。

备份恢复与 Agent 重装先暂停派发、对账后恢复；升级保护正在执行任务；测试配置导入禁用生产绑定。试点按测试数据→指定工位→受控扩大，旧路径回退须撤销新路径调度，禁止同一笔业务双路打印。

## 10. 测试与验收主题

L1 先平台原生身份/权限/菜单/File/Audit/初始化，再外部MES嵌入和无宿主装配；L2 三类/自定义/底稿/ZPL 模板与版本；L3 数据权威/保密/准备快照；L4 任务幂等/逐明细/未知结果；L5 Windows 生产同路径；L6 PDA 真蓝牙打印；L7 历史/重打/备份恢复；L8 实际项目/安装升级/诊断/试点。各任务细化对应负例，全部证据分清单元fixture、平台真实集成、参考宿主和真实客户；外部可用不能替代平台兼容。平台MES尚未开发的业务来源可用明确标注样例的公开DTO端口，不伪称真实MES联调，也不因此把平台身份/文件/审计全部Mock掉。
