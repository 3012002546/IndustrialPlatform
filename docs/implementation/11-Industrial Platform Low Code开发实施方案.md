# 1. 文档说明与输入

## 1.1 用户可见目标

工程师配置自有辅助台账、查询/列表/独立新增编辑详情、组合页面和注册代码页，完成字段绑定、业务动作、参数映射、试运行、授权发布与回退。整个Studio能独立部署并接到现有MES，四类产品各有独立菜单；本阶段交付共同基础和低代码，PF09加入看板、报表/Excel和追溯。

# 2. 定位、范围与边界

| 部分 | 首版交付 | 边界 |
| --- | --- | --- |
| DataSource / Dataset | API、受控只读库、参数化查询块/具名过程、字段/集合及参数配置 | 普通运行调用不提交任意SQL、URL或凭据；平台业务数据走公开合同 |
| LowCode | 自有辅助台账、三类页面、字段和注册动作配置试运行 | 不跨模块改库存/工单，不把ReferenceData当通用记录存储 |
| Publishing | 草稿、不可变修订、依赖校验、发布/回退及审计 | 回退发布指向不回滚已发生业务或物理表 |
| 交付 | 平台原生、独立、完全离线及外部MES接入 | 继承平台兼容范围；模拟通过不代替真实MES验收 |

不加入任意后端脚本、通用工作流、规则引擎或插件市场。复杂业务保留注册代码扩展；平台许可证尚未决定，受限第三方与客户实现只作参考。

# 3. 架构与纵向交付链

```text
注册API / 只读SQL或过程 → DataSource → Dataset参数/字段合同
                                           ↓
自有辅助台账 ← LowCode页面 / 字段 / 注册业务动作
                                           ↓
                           草稿 → 发布修订 → 受权运行
                                           ↓
                    PF09 Dashboard / Report / Traceability
```

同宿主通过公开应用端口协作，不跨模块Repository；分进程通过受信接口。PF09运行不加载LowCode设计器。独立部署明确所需身份、数据库、文件、审计与可选能力，不靠完整主平台或另建账号域冒充独立装配。

# 4. 数据、事务与初始化

| 归属 | 持久化对象 | 必须保持的语义 |
| --- | --- | --- |
| DataSource / Dataset | 来源/凭据引用、查询修订、参数Schema、字段/集合Schema、权限和执行预算 | 缺参不扩大查询；字段变化检查兼容；秘密只留服务端 |
| LowCode | 应用/页面修订、组件/字段/动作绑定、自有台账记录 | 约束、并发、字段变更/已有记录迁移、删除保留清楚 |
| Publishing | 草稿、发布指向、不可变模板和依赖版本 | 发布原子一致，草稿不影响线上；回退不改业务事实 |

完整字典见数据规格§2～3：source、resource/revision/grant、ledger_record/value、operation_receipt、audit_outbox。台账已选定固定记录表+类型索引，不动态建客户表；decimal索引用6位缩放有符号整数保证SQLite精度。兼容字段变更、非兼容变更拒绝、恢复与发布事务见§5。

初始化沿蓝图07/33的Topology及服务自有Migration/Seed/Verify，不使用EnsureCreated、不向SystemData传Secret；readiness读取本地事实。时间使用DateTimeOffset/UTC RFC3339，数量/金额按decimal精度和单位；业务修订、并发版本和文件内容版本分别表达。

# 6. API、动作与公开集成

接口规格§1～4已定义设计态试查、已发布Dataset运行、台账CRUD、Action、草稿/发布/回退的路径、DTO、权限、错误和幂等；数据规格§5定义事务。File/Audit/Scheduler公开适配见接口规格§8；明确标注已有与新增，不能调用私有Store。

Dataset只接受发布资源标识和声明参数，行列权限结合可信身份求值；Action由所属业务校验并执行，输入可来自当前行/表单/页面/常量。缺父行或必填不得发宽泛查询。试运行显示解析后的请求/结果，写动作明确使用模拟或隔离目标。只在真实可靠投递/消费需要时复用Outbox/Inbox，不机械加技术表。

# 7. 页面与设计交互

管理列表沿黄金页，独立新增/编辑/详情、组合页和注册整页分别可达；设计器分组件/结构区、主画布、属性/绑定区，试运行能核对字段及动作请求。四类产品是独立菜单，不是同页四个Tab。

工作台适配平台框架，1920×1080只作概念参考；支持拖拽、平移、缩放、Ctrl+Z撤销/Ctrl+Y恢复、返回保留草稿、侧栏收起重开。输入框原生撤销优先；缩放不修改模型坐标。选择/局部loading、异步旧响应、防重提交、错误/空态/冲突及三端差异沿平台规范。PageId、路由/权限、线框和错误态已在页面规格§2～7定义；真实浏览器验收按B用例执行。

# 8. 错误、安全与可观测性

区分查询失败、取消、空集合、超限和过期，错绑路径/类型定位到字段；缓存和回包按租户/权限/参数/版本隔离。只读过程核验实际副作用，不只检查名称；API目标受控，凭据不下发。导入模板与UI编辑采用相同白名单和权限校验。

审计、TraceId、耗时/数量/错误指标复用平台，不在日志记录凭据或业务全文。草稿保存冲突可处理，业务动作未知结果不自动重做有副作用操作。

# 9. 测试与验收

主要覆盖共享明细§4的A01～A04/A14，以及V0/V1、PS-01～PS-03/PS-09适用链。参数/字段/动作、授权和并发需可重复证据；拖拽/缩放/返回需真实浏览器；初始化/升级、Provider和约定客户端按平台范围核验。模拟业务数据不意味着身份/文件/审计全部Mock。

源码变化先新鲜Release构建再按仓库测试，未测/失败不算通过；文档整理只检查链接、编号、依赖、覆盖与diff。
