# 4. 核心配置与运行设计

## 4.1 看板数据与跳转

一个接口可返回整页数据，由页面命名实例统一刷新，各组件按路径绑定液位/温度/状态等属性；也允许多个实例。显示加载/错误/过期及最后成功时间，不把通信中断显示成零或正常。

列表事件选择目标看板，把当前行字段映射到目标声明参数；目标再映射参数到数据源查询条件。两端可试运行，显示源行、传参、请求和结果；缺必填不查全厂，服务端检查目标与数据范围。轮播只保存引用、参数、顺序、停留及播放行为，数据刷新另行配置。

## 4.2 主从明细与单报告

纸张母版定义尺寸、方向、页边距和页头页脚；画布体现PageHeader、Detail1主集合、Detail2及后续子集合、PageFooter。层级在结构区和标签表达，所有带同正文宽度，不逐层缩窄。每层明确父行、集合路径/关联查询、字段、排序和合计作用域，支持增删层级、拖拽控件和格式设计。

运行按实际集合展开，多工单/工序/明细不串上下文；表格区分当前带行与集合两种上下文，带内长内容通过跟随关系推动后续控件；单报表空数据可配置跳过/说明，组合空实例始终跳过。三级只作样例，不成为产品上限。查询报表明确条件、参数映射、分页及全结果生成，复用同一单报表资源。

## 4.3 两种组合与动态电子记录

简单组合：选独立报告/修订→映射参数→选择/排序→生成→保留或统一页码，不叠印。

电子记录：工单→实际工序→条件/数据匹配→0～N子报告实例→嵌套/重复/排序→连续内容流→分页。无数据跳过且不占标题/位置，失败与必需记录缺失独立表达。下一块填前页剩余空间，不默认每子报告新开页；整份主模板统一横向或纵向，子报告继承正文宽度，最终计算统一页头页脚与总页码。子模板可选择完整正文或任意明细带子树为输出起点，来源行/子集合及祖先上下文可映射；进入子模板编辑再返回保留母版状态，规则试运行显示具体源行和输出页段。

## 4.4 HTML、输出与在线Excel

消费来源系统已保存的HTML、实际填写值/勾选状态、表格/图片及资源版本，工单录入留后续MES。长段落/表格、超单页行/单元格续排；普通能容纳行按配置保持整行；不可拆图片缩放或明确报错。续页表头保留，不截断、不无故整块换页留大空白；设计试运行与PDF/打印核对内容不重不漏。

HTML脚本不执行，资源缺失/不支持格式不可静默删除后报成功。生成完成与生产完成/审核完成分开。Excel从上传或报表工作副本打开，保存经服务端确认产生内容版本，冲突/失败保留上一有效版本，归档不覆盖、业务源不回写。

## 4.5 追溯设计与事实查询

起点来自库存/工单等实际数据，配置搜索参数、返回集合、列和对象标识；方块绑定摘要/明细，连线绑定关系语义、正反向输入/返回映射和事实证据。节点/连线可拖拽，连接规则可校验，改变位置不产生实际消耗。

原料→预溶解→半成品→成品→销售出库是流程样例，另以序列号装配验证同一核心。任意节点继续上游/下游/双向查询，生产谱系与设备/质量上下文分开；多次真实关系不因相同端点误合并。明细外链/文件在当前页模态框，尊重目标嵌入和文件权限，不绕过CSP或强制新Tab。

# 7. 页面与设计操作

管理列表沿黄金页；设计器有结构/组件区、主画布、属性/数据/事件区和可达的保存/返回/预览。绑定面板展示字段树、上下文、请求及脱敏结果，不能只有SQL文本框。

工作台适配平台框架；看板默认1920×1080可调，报表纸张按模板。平移/缩放不改模型坐标或物理纸张；侧栏收起后能重开，不遮按钮/拖拽把手；必要滚动按区域归属，适应模式避免多余双向滚动。Ctrl+Z撤销/Ctrl+Y恢复，输入框原生撤销优先；返回保留草稿和合理上下文。逐页PageId、路由、权限、线框、加载和终端差异按页面规格§2～7执行，不能省略真实控件回归。

# 8. 错误、安全与可观测性

缺参、越权、空数据、失败、部分结果、超限和过期分别展示；追溯限制深度/时间/节点边数，支持取消，截断不报完整。源只有批次数据时不能宣称精确包装级追溯。

HTML净化、资源加载、Office会话和外链按可信来源限制，不能削弱CSP；字段/筛选/排序/合计/导出同授权。审计经IStudioAudit接原生或Embedded，TraceId/性能指标沿共用规范，不记录HTML全文和凭据。发布固定依赖、草稿不污染线上，回退不改事实。

# 9. 测试与验收

覆盖共享明细§4的A01～A03、A05～A16、V2～V7与PS-01～PS-10对应链。重点验证共享请求、双端传参、等宽可变层级、两种组合分别输出、HTML跨页不重不漏、Excel往返、多行业事实追溯、干净环境完全离线安装。

机制模拟、平台真实链和现场对照分开。用户控制生产接入，缺现场数据保持待验；正式源码变化先新鲜构建再按仓库测试，不用概念结果替代。文档整理不运行无关业务测试。
