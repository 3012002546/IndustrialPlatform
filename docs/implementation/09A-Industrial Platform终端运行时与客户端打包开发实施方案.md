## 1. 文档说明与当前输入

本方案是终端运行时、客户端打包、设备桥接与更新的唯一实施/Todo 维护源。设计依据为[蓝图 34](../blueprint/34-Industrial%20Platform终端运行时与客户端架构.md)、三端蓝图 04、服务边界 32、统一实施模板和参考对话《寻找PDA打包方案》的最终采纳结论。

2026-09-07 只读检查 develop / HEAD `8625efb`：现有 Vue3 工程和共享 API/Store/外壳存在，未发现公共 Device Runtime 或 Electron/Capacitor 原生工程；SystemData runtime 是控制面配置消费，不是硬件运行时。PF-05/06 尚未实施。本轮只写文档，目标目录不是已存在的代码，不创建安装包或运行设备测试。

执行位置：PF-05 Web → PF-06 Web → **PF-06A** → PF-07。Mobile 三端 Web 不延期，Mobile 原生平台范围由 001 明确；当前确定的容器是 Windows Electron 和 Android PDA Capacitor。

## 2. 定位与边界

拥有宿主能力、设备桥接、生命周期和安装/更新；不拥有消息服务、标签业务、称量判定或 MDM。保留 Vue3，不改用 React Native 重写 UI。首版不做 PC 单独 Web 热更新、多厂商 SDK 全覆盖、永久后台 BLE、静默 APK 安装、完整离线业务或复杂灰度平台。

## 3. 前后端与架构

业务页面 → 共享 Runtime 接口 → Web/Electron/Capacitor adapter → 浏览器/OS/厂商 SDK。业务请求仍使用平台共享 API client、可信身份与现有服务前缀，不经 Runtime 重建另一套认证协议。更新分发只托管签名清单/包；有现成发布能力时复用，不为首版新增核心 Service Host。

## 4. 目标目录和引用

| 目标路径（实施时核对） | 责任 |
| --- | --- |
| `src/frontend/src/platform/runtime/` | 类型、能力发现、Web 与原生 adapter 注册 |
| `src/clients/electron/` | main、preload、打包/更新配置 |
| `src/clients/pda/` | Capacitor Android 工程和 Kotlin/Java 插件 |
| `src/frontend/tests/`、`tests/Clients/` | 共享逻辑、桥接契约与真机脚本 |

厂商依赖只进入对应 adapter；页面不引用原生全局对象。现有共享组件/Store 继续复用；多进程不共享内存，事件经桥接去重且带主体 epoch。

## 5. 初始化与持久化

本阶段不是数据库 Service Host，不新增 Schema、SystemData 初始化单元或空账本。客户端安装配置、版本清单、更新暂存/最后良好版本、本地脱敏日志由容器维护；凭据放受支持安全存储，不写普通配置或日志。设备执行账本归 PF-10B Agent，当前不预建长期离线消息数据库。

时间用 DateTimeOffset/UTC RFC3339，超时用单调时钟。租户与用户来自可信身份，设备标识不是认证因素。插件权限、安装权限与平台业务权限分别验证。

## 6. Runtime 契约

| 能力 | 最小契约/行为 |
| --- | --- |
| capabilities | 容器、OS、NativeVersion/WebVersion/BridgeContractVersion 与 Supported/Unsupported/PermissionRequired 状态 |
| lifecycle | start/stop/resume、前后台/休眠、主体换人清理；resume 必须恢复权威状态 |
| scanner | acquire/release 当前输入会话；ScanResult(value, source, symbology?, receivedOn, sessionNId) |
| camera/bluetooth | 权限请求、取消、一次扫描、受权设备连接/读写/断连；不开放任意命令 |
| files/printer | 受限选择/预览/保存和批准打印能力，按实际支持说明；标签任务后续接 Agent |
| notifications/navigation | 应用/系统提醒、受权打开会话；点击后重新鉴权 |
| updater | check/download/verify/activate/status；Native/Web 兼容与忙闲状态门禁 |

稳定错误：RUNTIME_UNSUPPORTED、PERMISSION_DENIED、DEVICE_BUSY、DEVICE_DISCONNECTED、UPDATE_INCOMPATIBLE、UPDATE_SIGNATURE_INVALID；用户界面给重试/设置/稍后升级入口，不显示 JAR、IPC 等实现细节。

## 7. 页面与交互

“终端与版本”显示容器、当前版本、更新状态和可用设备；“扫码设置”只展示已支持模式与结束符；权限拒绝说明如何恢复，不能无限弹系统授权。PDA 工作页保持 48px、Mobile 44px 触控与软键盘安全区；PC 使用现有黄金页/抽屉。更新提示显示下载/校验/等待业务结束/可重启/失败恢复，用户看得懂当前是否能继续作业。

聊天列表/全屏、PC 抽屉/工作区及远程协助继续用原页面；Electron 关闭窗口、退出进程、托盘驻留分别约定；Mobile 原生未冻结范围不展示假完成入口。

## 8. 安全、设备和协作

按蓝图 34 第 3/5 节实施受限 IPC、Origin/导航、插件权限、广播来源、设备互斥、换人清理和后台恢复。打印、称量与共享的 busy 由各所有者提供，不在 Runtime 猜测业务完成。系统通知不得含敏感正文；服务端已保存消息与后台通知实际可达分别验收。

## 9. 更新详细流程

受信清单包含 Channel、NativeVersion/WebVersion、BridgeContractVersion、MinNativeVersion、ArtifactHash、Signature、下载位置和安全最低版本。校验清单来源与产物签名，限制下载目标；离线停留最后良好版本。下载→校验→暂存→等待安全点→激活→启动健康确认，任何失败回退并记录原因。Web 包不能调用当前原生没有的 bridge；插件、JAR/AAR、权限清单变化走 APK 完整升级。

PC 首版完整安装包更新；PDA 分别做 Bundle 与 APK。实施 001/005 评估 electron-builder/electron-updater、Capacitor 更新插件或自托管方案的版本/许可/离线可用性，尚未锁定不能写已采用。

## 10. 验收矩阵

R1：浏览器回归与三容器相同业务页；R2：Windows 安装/安全 IPC；R3：真 PDA 文本框/广播/相机/BLE；R4：PC/Bundle/APK 三种升级及损坏/中断/回退；R5：聊天、共享、换人、锁屏恢复；R6：内网交付与诊断。各任务下的具体负例均为门禁，保留软件版本、设备型号、固件、权限、日志与截图证据。
