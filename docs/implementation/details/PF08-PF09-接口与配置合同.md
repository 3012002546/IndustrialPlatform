# PF08 / PF09 接口与配置合同

## 2026-10-27 看板导航参数、选行与查询范围修复

导航、条件判断及返回状态统一使用DatasetValues解析后的页面参数，应用defaultValue并由服务端重建TrustedContext；草稿试运行的目标查询诊断也使用目标页面解析后的参数。客户端提供的可信参数原值不参与导航条件和映射。

RowClick通过相同的StudioBinding解释器解析rows，支持直接Constant绑定、页面共享Instance及旧props.instanceId/collectionPath。按rowKeyPath重新查找授权集合，不接受客户端行正文；结果存在重复的非空行标识时返回409/STUDIO_ROW_KEY_AMBIGUOUS，不再默认取第一行。

导航仅执行当前规则parameterMap、enabledWhen及选行集合引用的实例，并递归执行显式dependsOn和参数Instance依赖；Constant值中的JSON不作为绑定遍历。页面所有动态依赖的Run权限、固定修订、启用状态和来源合同仍校验，同一数据集/修订在一次页面执行中复用刚校验的文档。实际源端查询继续校验参数、字段、工厂范围、来源与预算；无跨请求授权缓存，不合并不同实例的查询或改变其参数/刷新周期。普通整页、局部刷新、版本切换及匿名链接撤销复核保持原合同。

## 2026-10-27 原生匿名读取的安全状态复核

HTTP大屏入口和调用参数不变。开发环境成功响应增加只含固定阶段名称及毫秒的Server-Timing，不输出凭据、账号、业务参数和SQL；生产环境不返回阶段诊断。

Identity授权快照增加可选RoleNIds元数据，由同次权威查询中的活动角色事实产生，旧适配省略时保留原读取链。IManagementStore增加GetUserSecurityStateAsync，返回TenantNId/NId/Name/Status/IsDeleted/AuthVersion；原生实现独立查询当前用户行，旧实现可经默认聚合读取兼容。该返回不得替代授权快照，授权快照也不得替代此用户状态复核。

原生大屏复用同次快照的角色/权限，随后仍独立检查新读取用户的租户、主体、删除、禁用、安全版本；两次AuthVersion不一致也拒绝。工厂映射同时消费已复核的主体和同次角色事实，无跨请求授权缓存，无ALL或其他角色兜底。Run/Publish、目标、可见行、参数推导、固定修订和链接撤销末尾复验保持。

## 2026-10-27 看板数据源增补合同

一个API实例可返回对象结构，多个组件以不同path绑定同一响应；一轮对该实例仅查询一次，与组件个数无关。多个实例即使引用相同操作也有各自参数/周期，不承诺跨实例、跨页面或跨设备全局去重。独立接口复用同一发布数据集/来源授权与预算合同，仅在确需独立参数或周期时使用。接口数据集先由登记来源创建并发布；看板不能越过登记直接调用任意URL。组件库仅呈现32类可视组件，原35类运行注册保留兼容。

Dashboard.instances增加可选sourceType：缺省Dataset兼容旧文档；Api必须引用query.kind/type=Api的已发布Dataset固定修订；Constant须声明value（包括null），refreshSeconds为0或省略，不需要Dataset依赖。label用于展示，scopeComponentId标识组件独立接口的设计归属，不形成额外权限。每页最多64实例，组件仍用`{from:"Instance",instanceId,path,nullPolicy}`绑定；任意组件已登记的可绑定属性均可使用同一实例。所有数据读取继续复用Dataset的参数、可读字段、行权限、源端登记、预算和错误契约。

动态实例refreshSeconds为0～86400整数：0仅初次/手动，正数在上次读取完成后计时。staleAfterSeconds为1～86400。看板查询跳过Dataset结果缓存以实际访问源端；其他Dataset调用保持原缓存规则。参数可映射Constant、PageParam、Instance和可信Context，依赖解析同时考虑dependsOn和Instance参数引用，拓扑执行、单次去重并拒绝循环。

`GET /dashboards/{nId}/runtime`与`GET /screens/{id}/runtime`增加可选query.instanceIds（JSON字符串数组），`POST /dashboards/preview`增加可选body.instanceIds；省略执行全部，空数组不执行外部查询但仍校验全部动态依赖的权限/来源合同。局部结果仅含执行过的实例及其依赖。屏幕读取可带knownRevisionNId；发布版本变化时忽略局部选择并完整读取，服务器在该次请求固定已解析的修订。屏幕前端最长30秒请求一次元数据心跳，用于复验链接/发布版本，不擅自把慢数据源缩成30秒外部查询。

瞬时源端5xx、429和超时返回实例`{data:null,error:{code,message},quality:{status:"Error"}}`，信息不含源端响应正文；前端合并时保留上次data并呈现失败标记。依赖失败不执行下游。401/403、来源或修订改变不转换为正常空数据；公共大屏拒绝访问时清屏。初次/手动与周期读取使用同一运行渲染。运行端不接受任意URL、SQL、凭据或脚本。

版本：V1.4；2026-10-22。PF08当前树开发与自测进行中，待用户验收；PF09接口仍为详细设计合同，不能因共用接口或空表存在记为交付。当前已实现范围及阶段证据见[PF08证据](../../evidence/PF-08.md)，下文验收规则不等于已通过。与[数据模型](PF08-PF09-数据模型与生命周期.md)、[运行规则](PF09-报表分页与追溯运行规则.md)、[页面验收](PF08-PF09-页面与验收规格.md)配套。本轮按概念v7.7补齐组件目录、表格行模式、子模板输出起点和查询/追溯绑定，见[对齐复核](../../evidence/2026-10-21-platformstudio-concept-alignment.md)。

## 1. HTTP、类型与权限

统一前缀 `/api/v1/studio`，Gateway保留原路径；同宿主调用同一Application端口。成功由既有ResultFilter包装ApiResult，失败沿`ApiResult.Fail`；下文JSON均指**Data负载**，不得再嵌第二层自造信封。校验失败的Data为`{errors:[{code,path,message}],traceId}`。DTO字符串/枚举允许可空入站后统一验证，避免自动Required返回另一种错误格式。

所有NId字符串≤128；revisionNId是不可变修订的NId，revisionNo/optimisticVersion/stateVersion/contentVersion/totalCount都是十进制字符串；ConcurrencyVersion是GUID。`VersionCommand={optimisticVersion,concurrencyVersion}`。不能把JSON中的数字字符串隐式转Number。数量decimal采用字符串，坐标/字号等有界显示数字可number。

列表Query：`keyword?<=128,status?,page=1,pageSize=20(1..200),sortBy=name|createdOn|lastUpdatedOn,sortOrder=asc|desc`；只能字段白名单。返回`{items:[],page,pageSize,totalCount:"0"}`，最后按Id稳定排序。没有selection需求的管理列表不开复选。

权限码前缀`studio`：`source.view/manage/test`、`dataset.view/design/publish/run`、`lowcode.view/design/publish/run`、`ledger.read/write`、`dashboard.view/design/publish/run`、`report.view/design/publish/run/export`、`trace.view/design/publish/run`、`workbook.view/edit/export`、`resource.grant`、`deployment.inspect`、`audit.view/export`、`report.reconcile`。同时检查资源grant及数据策略；身份/租户/工厂范围从服务端验证后的统一可信上下文取得（平台原生由Identity提供，外部由MES身份适配提供），禁止参数覆盖。Dataset/模型发布不授予使用者超出其业务数据权限的访问权。

写命令除草稿PUT与幂等状态设置外必须带`Idempotency-Key`（1..128 ASCII，不含用户数据）；同租户/操作/key+不同规范化body hash返回409 `STUDIO_IDEMPOTENCY_CONFLICT`。不会执行第二次副作用。草稿保存使用双版本；离线客户端保存需同样CAS。

`GET /capabilities`供当前用户进入工作台时读取，Data=`{coreReady,deploymentMode,profileVersion,modules:[{key,installed,enabled,available,reasonCode?,capabilities:[{key,status,reasonCode?,checkedOn?,receivedOn?}]}],generatedOn}`；只返回其有功能查看权的模块，不含连接/秘密；未安装的授权目标可仅返回不可用诊断，不据此注册菜单/API。菜单可用性=可信功能授权∩已装配模块；能力未就绪仍有明确诊断，不能靠前端自行猜服务端口。状态Ready/Degraded/Unknown按真实来源计算，generatedOn不能把旧检查变新。部署、身份及外部审计入口和DTO以[适配部署规格§4/7/9](PF08-PF09-双模式适配与按需部署.md)为准，按同一错误与类型合同实现。

2026-10-26新增单看板设计文件合同：设计器提供“导入设计 / 导出设计”，文件后缀`.dashboard.json`、UTF-8、上限2MiB，格式为`{format:"IndustrialPlatform.DashboardDesign",version:1,name,exportedOn,document:DashboardDocument}`；同时接受直接保存的`schemaVersion:1`看板document。document保留画布、组件/属性/绑定、参数、数据实例固定引用、导航以及可选theme/samples。文件不携带resource身份、授权、连接配置、来源秘密或运行查询结果；常量绑定中的演示数据属于设计内容。

导出当前编辑态（包括未保存调整），下载前通过既有draft读取重新验证Design能力。导入先检查文件大小、格式、版本和基础结构，再对当前resource调用既有validate；校验失败保持原画布，成功后由用户确认应用，作为一次可撤销的草稿改动，不自动保存、发布或授权。当前resource身份与名称保持自身归属，依赖数据集/目标资源须在当前环境存在且可访问，缺失时返回原验证诊断。跨资源依赖打包与资产转移继续沿上表packages合同，本轮单设计文件不新增ZIP端点或发行能力。

创建资源同事务写创建者五项resource grant，实际能力仍与当前模式可信功能权限取交集；不授予没有功能权限的人发布权。其他用户经显式Role/User grant访问。工作簿不是resource kind，首版访问规则为workbook功能权限+拥有者；由报告建副本还需源产物读取权。其他用户需要创建自己的授权副本；不暗中引入共享工作簿ACL产品。

## 2A. 独立匿名大屏（2026-10-26 C2 增补）

管理端运行页新增“大屏链接”，须具备`studio.dashboard.publish`功能权限和资源Publish grant；生成时同时核验Run、数据集/来源及参数。大屏是单独顶级路由`/screen/dashboards/{screenId}#key={secret}`，不进入PC菜单/工作区，不恢复系统会话。普通`/pc/studio/dashboards/{nId}/run`和原运行API仍要求登录。

| 接口 | 输入/输出 | 边界 |
| --- | --- | --- |
| GET /dashboards/{nId}/screens | →最多100条`{id,revisionNId,createdOn,expiresOn,revokedOn,followPublished}` | 当前租户、当前资源Publish；无明文密钥；无到期值表示无限期 |
| POST /dashboards/{nId}/screens | `{revisionNId,parameters,lifetimeHours:null,followPublished:true}`→`{id,key,revisionNId,expiresOn,followPublished}` | 默认无限期、跟随最新发布；有限期1～2160小时；密钥仅生成时返回；参数64KiB以内 |
| DELETE /dashboards/{nId}/screens/{id} | →`{revoked:true}` | 当前租户、当前资源Publish；记录撤销审计 |
| GET /screens/{id}/runtime | `X-Dashboard-Screen-Key`→运行投影+`parameters,expiresOn,followPublished` | 匿名但必须持有有效密钥；不接收修订/参数覆盖；`no-store`；同IP每分钟60次 |

2026-10-27增补：`lifetimeHours:null`或不传表示无限期，API无到期值，前端显示“无限期”；`0`仍是非法服务端期限值，不用极远日期伪装无限期。`followPublished:true`每次运行读取同一个资源的当前PublishedRevision，参数保持建链时固定值；只有保存草稿时不切换，发布/回滚后在下一次自动刷新生效，默认30秒内，手动刷新立即取当前发布版，不需要换URL。`followPublished:false`固定创建时选择的已发布修订，不随新发布改变。生成时核验输入修订属于当前看板；跟随模式按当下最新发布文档验证参数与依赖。新版本修改必填参数而与原固定参数不兼容时明确报错，不回退旧版或扩权。

新建链接界面默认“无限期 / 跟随最新发布版”，同时保留1/7/30/90天和固定版本选择。10月26日已经发出的链接经增量迁移仍保持有限期、固定原修订，不自动升级规则；需要长期跟随时新建相应链接。无限期仍可撤销，仍重验发布者和资源授权，绝非无限期身份缓存。

每次匿名刷新从权威目录重取发布者状态、授权版本、权限、角色和工厂范围，再执行既有看板/数据集运行链。停用/删除资源、撤回Run/Publish grant、停用发布者或安全版本变化均使链接停止展示；退出发布者浏览器不会撤销独立展示。查询结束再核验链接，撤销或过期后不返回数据。公开投影清除导航，观看端不开放跳转、编辑或参数表单；仅固定展示和刷新。链接失效不跳转登录，清除旧画面并显示失效提示；网络失败显示重试状态，卸载取消请求和定时器。

服务端用32字节密码学随机密钥，库内仅保存SHA256摘要并固定时间比较；浏览器只从fragment读密钥，通过专用请求头发送，不附加Cookie/Authorization，不经过登录刷新拦截器。生成、撤销审计不记录密钥或运行数据。默认30秒刷新，实例声明更短周期时最低5秒；画布按视口Contain等比适配，支持浏览器全屏及F11降级提示。

本轮支持PlatformNative的Identity权威目录和独立LocalAdmin目录；MES/OIDC仅有浏览器会话上下文、无无会话委托合同，拒绝生成此类匿名链接，不复制外部会话为长期身份。大屏设备访问地址采用部署方实际可达的HTTPS域名；本机7260仅为合成数据验收服务，不是已完成局域网/现场发布。

DatasetResult=`{schemaVersion:1,revisionNId,requestId,data,observedOn,receivedOn,sourceVersion?,consistency,quality:{status:Fresh|Stale|Unknown,basis:SourceTime|AcquisitionOnly,sourceObservedOn?,reasonCode?},elapsedMs,rowCount:"…",truncated:false}`。observedOn为本次取数时点，receivedOn为Studio收到响应的时点；两者不能冒充设备采样时点。同步执行超过总量直接STUDIO_LIMIT，不能返回无标识截断成功。预览取样max100行、生产常规默认10000行；报表可达来源允许maxRows并受总预算控制。分页只用于声明支持分页的数据集，不对已获取数组假装全库分页。

### 3.2 Dataset document（完整字段）

| 属性 | 类型 / 必填及默认 | 规则 |
| --- | --- | --- |
| schemaVersion | int=1 | 必填 |
| sourceNId / sourceConfigurationVersion | string / version字符串 | 发布固定来源合同 |
| query | tagged union | Api:{operationKey,method:GET/POST,parameterMap}；Sql:{statement,parameters}；Procedure:{qualifiedName,parameters,resultSets}；三者不能混填 |
| parameters | ParameterDef[] / [] | 下表 |
| result | FieldDef | 根Object或Array；包含所有子集合结构，不能只给平面列名 |
| rowPolicyKey | string | 必填，代码注册的数据范围策略，`public`也须显式登记；不接受任意SQL表达式 |
| readableFieldIds | string[] | 可读字段白名单，默认空拒绝；过滤/排序/合计同授权 |
| timeoutSeconds / maxRows / maxBytes | int / int / string | 默认30/10000/10485760，不能超过source/部署限额 |
| cacheSeconds | int=0 | 0..60；按租户+授权指纹+修订+参数隔离；报表事实采集默认0 |
| freshness | {mode:AcquisitionOnly/SourceTime,timePath?,maxAgeSeconds?} | 默认AcquisitionOnly，此时quality=Unknown且说明“来源未提供采样时间”；SourceTime须声明结果中的UTC时间路径及有效期，缺值/非法时间为Unknown，超期为Stale。不能用本次请求成功把旧源时间改为Fresh |
| pagination | null或{mode:Offset/Cursor,defaultSize,maxSize,stableSortFields,input:{offsetParameter?,limitParameter,cursorParameter?},result:{rowsPath,totalCountPath?,nextCursorPath?}} | source声明支持才允许；maxSize≤200；参数引用已声明查询参数，结果路径引用结果Schema；Offset须有totalCountPath，Cursor须有nextCursorPath，不能从当前页长度推算总数 |

ParameterDef=`{name,label,type,required,nullable,defaultValue?,enumValues?,maxLength?,min?,max?,source:Caller|TrustedContext,contextKey?}`。type=`String/Int32/Int64/Decimal/Boolean/Date/DateTime/Guid/Array`；Array另有itemType并最多1000元素。required不等于非空字符串，字符串必填trim后非空。TrustedContext只允许tenant/user/authorizedFactoryIds等注册键，来值覆盖请求同名值并记录诊断，不将授权范围放进普通可编辑参数。

FieldDef=`{id,name,label,type,nullable,children?,item?,format?,sensitive:false}`；Object有children，Array有item，标量不得嵌children。id稳定，name为数据实际属性名；重命名通过映射保留id。禁止`__proto__/constructor/prototype`属性路径。日期仅DateTime含时区；Date为yyyy-MM-dd业务日期不当UTC时间点。

有pagination的数据集另返回`pageInfo:{mode,page?,pageSize,totalCount?:十进制字符串,nextCursor?}`；保持data原声明形状，表格/追溯仍按配置collectionPath取行。分页输入由执行器按合同映射到查询参数，不能被普通Form绑定覆盖。无pagination时，在maxRows范围内完整取数后可在授权结果集本地分页，须标明“全量已加载”；超过限额报错，不伪造总数。查询报表首版页码分页使用Offset或已完整加载集合；Cursor源使用上一批/下一批，不显示虚假页码/总数，Query响应totalCount可为null并带nextCursor。生成完整报告要迭代全部源页并遵守快照/预算，不用最后一页的时点冒充整体一致快照。

SQL只在设计态登记、参数化执行，运行DTO绝不含SQL。允许SELECT/CTE只读语句，限制目标对象；**语法检查不是只读保障**，必须只读账号+权限清单。SQL Server具名过程需独立人工/代码登记的只读准入和最小EXEC权限，可能写入/动态跨库的过程拒绝登记。Procedure的`resultSets=[{index:0,name:"rows",schema:FieldDef}]`，多结果集按固定name组合Object，数量/Schema不符报错。SQLite外部来源用只读文件连接。API的POST仅允许登记为无副作用的查询操作。

### 3.3 Binding / Condition / Sort（全模块共享）

Binding=`{from:PageParam|Row|ParentRow|Root|Instance|Form|Node|Constant|Context,path?,instanceId?,contextBandId?,value?,transform?:{kind:ToString|ToDecimal|DateFormat|EnumMap,args},nullPolicy:Error|Null|Default,defaultValue?}`；除Constant必填path，Constant必填value；Instance必填instanceId。path是字段路径数组，如`["equipment","tank","level"]`，只允许属性及确定数组下标；不支持JS/eval/任意函数/网络。ParentRow指直接父上下文；更高祖先显式contextBandId，发布验证其为祖先。Node只在追溯关系/明细上下文可用，指服务器校验后的`{key,objectTypeId,identity,summary}`，不能由浏览器任意造节点。target属性由映射项`{target,source:Binding}`给出，target必须是声明字段/参数。

Condition=`{op:And|Or,items:Condition[]}`或`{op:Eq|Ne|Gt|Ge|Lt|Le|In|IsNull|HasRows,left:Binding,right?:Binding}`；无脚本，递归上限32是保护预算，可受控提高，不能把三级样例写成产品层级上限。Sort=`[{fieldId,direction:Asc|Desc,nulls:First|Last}]`；服务器稳定补充主键排序。

上下文边界固定：Root只在报告中指当前根主记录（例如当前工单），不是跨全部工单共享变量；Instance指已命名页面数据实例的data根。LowCode/Dashboard不提供Root别名，避免多个实例含义不明；它们使用Instance/PageParam/Row/Form。ParentRow只在确有父层的报告/组装上下文可选。Default空值策略必须给类型匹配的defaultValue。

```json
{
  "instanceId": "lineData",
  "datasetNId": "DS-LINE-DETAIL",
  "revisionNId": "REV-LINE-3",
  "parameters": [
    {"target":"lineCode","source":{"from":"PageParam","path":["lineId"],"nullPolicy":"Error"}}
  ],
  "refreshSeconds": 5,
  "staleAfterSeconds": 15
}
```

PageInstance统一上例字段，另可`dependsOn:instanceId[]=[]`（无环）；相同实例一次刷新只执行一次。首次/参数变化先Loading，错误保留最后成功值但明确Stale/Error，不能填0。参数变动取消旧请求并以generation号丢弃旧回包；离开页面清timer/订阅。transport状态与Dataset质量分开：HTTP成功不代表源数据Fresh；缓存命中保留原observedOn/sourceObservedOn，前端展示最后成功取数时间及来源采样时间/未知原因，不能把页面重绘时间作为新鲜依据。Unknown质量不等于取数失败，可展示已取得值并附原因；不能因此无条件禁用历史报表或把同名质量状态当作Scheduler的Unknown运行状态。

Transform的args固定：ToString=`{}`（Invariant显示转换）；ToDecimal=`{scale:0..6}`（超精度错误）；DateFormat=`{pattern:"yyyy-MM-dd"|"yyyy-MM-dd HH:mm:ss",timeZone:"UTC"|已登记IANA时区}`；EnumMap=`{entries:[{from,to}],onMissing:Error|Original|Default,defaultValue?}`。不自动把空串/null转0。Context/Node只能在服务器提供该上下文的环节选择，设计器隐藏无效上下文且发布再次校验。

## 4. LowCode与台账

LedgerModel document=`{schemaVersion:1,fields:LedgerField[],numbering:{mode:Manual|Rule,ruleKey?},displayFieldId}`。LedgerField=`{id,name,label,type,required:false,nullable:true,defaultValue?,maxLength?,scale?,enumValues?,queryable:false,sortable:false,unique:false,caseInsensitive:false,retired:false}`。type=`String/Text/Decimal/Int32/Boolean/Date/DateTime/Enum/FileReference`；queryable字符串最长512，长Text不建索引。FileReference存`{fileNId,referenceNId,name}`，不接受本机路径。首版无任意公式物化字段；显示计算用注册Formatter。

LowCodePage document=`{schemaVersion:1,mode:Crud|Compose|Code,parameters:ParameterDef[],instances:PageInstance[],layout:LayoutNode,fields:FieldBinding[],actions:ActionBinding[],codeComponentKey?,ledgerModelRevisionNId?}`。LayoutNode=`{id,type,registryVersion,props,children:[],grid:{span,order,minWidth}}`；type来自代码组件白名单，props按组件Schema拒绝未知项；Crud提供查询/列表/独立新增编辑详情路由，Compose同样可嵌表单表格/树/Tab/附件，Code需要登记key。组件内Tab不替代四模块独立菜单。

FieldBinding=`{componentId,property,source:Binding,writeTarget?:fieldId,readOnly,visibleWhen?:Condition,requiredWhen?:Condition,validators:[{kind:Required|Range|Length|Pattern,options}],formatterKey?}`。客户端验证只改善体验，服务端重新验证。

ActionBinding=`{id,label,event:Click|RowClick|Submit,actionKey,executorVersion,inputMap:[{target,source}],enabledWhen?,confirmText?,success:{refreshInstanceIds:[],closeForm:false,navigate?}}`。Catalog ActionDef=`{key,inputSchema,outputSchema,permissionKey,mutating,idempotency:Required|None,preview:Mock|ReadOnly,executorVersion}`；发布固定executorVersion，代码升级保留兼容版本或拒绝旧合同，不能默默换行为。业务URL/HTTP方法/凭据由服务器注册，页面不能覆盖。设计试运行对写动作只走独立模拟执行器，清晰显示“模拟”，不调用生产动作。

Compose初始没有Row时，依赖Row参数的实例及其下游暂缓，`instances.<instanceId>={status:"AwaitingRow",reasonCode:"ROW_REQUIRED",path:"instances.<instanceId>"}`；不调用该实例的取数执行器，不注入可供绑定消费的Instance数据，不发detail查询。字段来源或条件依赖Row、或引用AwaitingRow实例时，保留componentId/property并返回`{visible:true,value:null,readOnly:true,status:"AwaitingRow",reasonCode:"ROW_REQUIRED",path:"fields[i]"}`。这表示等待选行，不能显示伪造空业务值或把未查询状态报为Fresh。

选行请求仅传`context.rowKey={instanceId,key}`；服务端重新执行已授权的Table主实例Dataset，按已发布`Table.props.collectionPath`找到结果中的行对象数组，再以rowKeyPath选出可信Row，同次请求按“主实例→可信Row→detail”加载依赖。collectionPath为受限string[]，默认[]，支持如["rows"]或["data","items"]的嵌套集合，不猜第一个数组；裸`context.row`在正式运行中返回422拒绝。集合内任意重复键返回409 `STUDIO_ROW_KEY_AMBIGUOUS`，当前授权结果找不到key返回404；不能用浏览器传入的Row、缓存行或静态下标绕过撤权和工厂范围。

AwaitingRow只用于页面实例和字段的等待呈现，不放宽真实动作。真实动作仍按rowKey和发布Dataset重查可见记录，再严格解析输入映射、条件、Schema和Form；缺Row不能获得该绑定或执行写操作，form仅接受声明字段。打开详情/新增/编辑沿业务页，失败保留输入，不刷新整个设计器。

LowCode内置注册控件最小props合同：Container/Grid=`{columns:1..24,gapPx:0..48}`；Text=`{text,styleId?}`；FormField=`{fieldId,control:Text/Number/Select/Date/DateTime/Checkbox/BusinessSelector,placeholder?,optionsDatasetInstanceId?}`；Table=`{instanceId,rowKeyPath,collectionPath?:string[]=[],columns:AppDataTableColumn[],queryMode:top|header,selection:none|single|multiple}`；Tree=`{instanceId,keyPath,labelPath,parentPath}`；Tabs=`{items:[{id,label,childLayoutId}]}`；File=`{multiple,maxCount:1..20}`；Chart使用§5.1图表合同及components/studio/shared/ChartRenderer；只复用合同与共用渲染器，不引用Dashboard模块；RegisteredPage/Component=`{registryKey,registryVersion,parameters}`。未知props拒绝，不透传事件名/HTML属性。Table显示/筛选/排序字段必须在Dataset允许字段中；复用AppDataTable请求和事件，不新建另一套表格。

低代码File字段沿现有File上传/个人引用公开合同，保存前服务器验证文件与引用匹配且当前用户有权；台账可见不等于附件自动取得读权。其他用户打开仍经File权限拒绝或允许，不能为共享记录绕过File授权。需要业务归属的报告产物/工作簿采用§8.1新增owned-reference。

## 5. Dashboard与轮播

Dashboard document=`{schemaVersion:1,canvas:{width:1920,height:1080,background,fit:Contain|Cover|Actual},parameters:ParameterDef[],instances:PageInstance[],components:DashboardComponent[],navigation:NavigationRule[]}`。width/height整数320..16384；变更画布尺寸默认保留坐标并提示越界，只有显式“等比缩放内容”才改坐标。

DashboardComponent=`{id,type,registryVersion,name,x,y,width,height,rotation:0,zIndex,locked:false,visible:true,props,bindings:[{property,source}],events:ruleId[]}`。几何为逻辑px、有限数，width/height>0；type由注册组件Schema约束；工业组件每属性独立绑定。图元位置/样式与数据值分开，不把运行值写回模板。时间、图表、仪表、数值、表格/滚动列表、文本、图像/SVG、状态图、轮播、按钮、容器、进度、水位、罐/泵/阀/管道/灯均有组件注册定义和属性面板；嵌入页仅受信白名单并沙盒化。

NavigationRule=`{id,componentId,event:Click|RowClick,target:{kind:Dashboard|LowCodePage|Report|BusinessPage,resourceNId?,routeKey?},parameterMap:[{target,source}],openMode:Current|Modal,enabledWhen?:Condition}`。Dashboard目标参数根据目标已发布合同选择；保存记录目标资源及设计时合同hash，发布锁入依赖版本。运行版本跳转目标仍用发布时固定版，目标停用/撤权则拒绝。行点击的Row为实际数据行对象，不绑定静态数组下标。

跳转只在用户触发事件时解析，不递归加载目标的所有跳转。发布依赖按(resourceNId,revisionNId)判环/去重，不能仅按resourceNId把A/B互相跳转判为非法；例如A新修订→B已发布修订→A旧修订是有限依赖。返回来源使用导航栈中原资源修订/参数/筛选/视口，不强迫再写一个反向规则，也不悄悄回到不同版本。

```json
{
  "id":"line-click",
  "componentId":"today-lines",
  "event":"RowClick",
  "target":{"kind":"Dashboard","resourceNId":"DB-LINE"},
  "parameterMap":[{"target":"lineId","source":{"from":"Row","path":["lineCode"],"nullPolicy":"Error"}}],
  "openMode":"Current"
}
```

上例须与§3.3目标页实例映射联测：`row.lineCode=L02 → page.lineId=L02 → dataset.lineCode=L02`。三段全部可选字段，无专用硬编码lineId分支。页面参数只承载标量/允许数组，长度合计16KiB；不把密钥或整行业务JSON写URL。

Playlist document=`{schemaVersion:1,parameters:ParameterDef[],items:[{id,dashboardNId,parameterMap,staySeconds,enabled}],loop:true,onFailure:Skip|Pause,preloadCount:1}`。停留3..3600秒；同看板不同参数允许重复。每项失败显示错误且按配置跳/停；预加载仍检查权限，最多下一项，不重复轮询后台页。

公共参数只在设计器定义，可移除；存在PageParam引用时确认后同时移除相应映射，取消则保持原状。运行页和独立大屏均不显示参数编辑表单，继续使用默认值/调用参数及每项映射。共用PlaylistRuntimePage负责定时播放、上一项/下一项、直接选项、暂停/继续、方向键及全屏；手动切换重置当前项停留计时，暂停状态下手动切换仍保持暂停。

独立轮播大屏按实际运行画布容器占满视口并Contain等比居中，控制条在底部居中；鼠标悬停底部操作区时显示、移开隐藏，不因其他画布区域移动持续显示。键盘聚焦与触摸操作仍可使用，展开的选项菜单属于同一操作区。普通管理运行页保持原布局。

轮播切换过渡保留上一次已授权画布及对应参数，在目标运行结果通过校验后同步替换；等待中禁止旧画布点击，失败或链接失效清除旧数据。首次加载使用紧凑、适配大屏深色背景的加载态，不将通用浅色骨架行铺满视口。

运行去重：系统内轮播导航同看板一样请求includeRuntime，复用既有一次性交接，Current/Modal不再重复读已返回的目标运行结果。匿名大屏命中有效预载仍逐次复核权限，使用instanceIds=[]避免重复目标取数；参数变化且目标修订相同的部分响应须补取全量，修订变化的全量响应直接采用。轮播网址已有item/navigation时直接恢复该项目及随响应返回的manifest；单项循环不预载/轮转自身，但数据和链接校验按原周期继续。轮播运行摘要复用同请求已读当前发布修订，不跨请求缓存授权。

轮播大屏复用DashboardScreens、StudioScreenLink/IStudioScreenStore、密钥、审计、发布者身份和授权，以及DashboardScreenLinks弹窗，不另建轮播链接服务/表。管理API=`GET/POST /api/v1/studio/playlists/{nId}/screens`、`DELETE /api/v1/studio/playlists/{nId}/screens/{id}`，创建合同与看板一致（可无限期、跟随轮播最新发布版或固定版、复制及撤销历史）；公开URL=`/screen/playlists/{id}#key=...`，密钥只在fragment与专用请求头，无Cookie/Authorization。仍走同一`GET /api/v1/studio/screens/{id}/runtime`：无playlistItemId返回精简manifest；有playlistItemId时由服务端选择已启用项、固定目标修订、按链接固定参数解析映射，返回DashboardRuntime并附playlist manifest；可携navigation规则/行键下钻，不接受观看者指定目标/任意参数。Manifest不暴露参数定义、映射或目标ID/修订。跟随发布指轮播修订，项目看板仍按该轮播固定的依赖修订运行。

每次公开读取继续检查链接、发布者安全状态/AuthVersion、根Run/Publish、目标Run、授权行和来源配置，返回前再次实时检查链接撤销/到期；静态画面也按30秒检查，权限失效清屏。RuntimeAuthorizedAsync仅复用本请求已授权的资源/修订，不跨请求缓存权限；普通看板资源/修订各读1次、根Run/Publish授权2次，轮播项目根与目标各读1次、授权合计3次。

API：`GET /dashboards/{nId}/runtime?revisionNId=…`→发布投影；`POST /dashboards/preview`请求`{document,parameters,selectedComponentId?,sampleRow?}`→`{instances,bindings,navigationPlan,diagnostics}`；`POST /dashboards/{nId}/navigation/resolve`请求`{revisionNId,ruleId,rowKey?,parameters}`→`{targetResourceNId,targetRevisionNId,parameters}`（服务器重验行/权限）；`GET /playlists/{nId}/runtime`→固定项及参数合同。实际取数统一Dataset.execute，不另造每组件接口。

## 6. Report / ReportBundle配置

Report document完整字段：`{schemaVersion:1,mode:Fixed|Query,parameters:ParameterDef[],instances:PageInstance[],query?:QueryReportDef,paper:PaperDef,bands:BandDef[],styles:StyleDef[],assets:AssetRef[]}`。依赖由发布器计算，不信任客户端填的闭包。Fixed与Query都使用同一带/控件输出内核；Query另配置查询表单和结果表，不另外存一份与打印内容分离的模板。

| 类型 | 字段与约束 |
| --- | --- |
| PaperDef | size:A4/A3/Letter/Custom；orientation:Portrait/Landscape；widthMm/heightMm（Custom必填，其他按标准）；margin:{top,right,bottom,left}默认15mm；headerHeightMm:15、footerHeightMm:10；所有空间合计必须有正正文区 |
| BandDef | id、kind:PageHeader/PageFooter/Detail/GroupHeader/GroupFooter/ReportHeader/ReportFooter；name；parentBandId?；data?:CollectionBinding；heightMm；grow:true；repeatOnPage:false；keepWithNext:false；controls:ReportControl[]；sort:Sort；group?:{keys:Binding[],pairedBandId}（Group必填）；emptyBehavior:Skip/Label（默认Skip）、emptyText?（Label必填） |
| CollectionBinding | mode:RootPath/ParentPath/Dataset；instanceId?、path?、datasetRevisionNId?、parameterMap?、filter?:Condition；RootPath从页面实例取，ParentPath从指定父带当前行取，Dataset模式用父字段批量关联；filter在候选集合每行上下文求值，缺路径是错误，空数组才空 |

带在画布上**永远同正文宽度**，parentBandId只决定展开上下文和顺序。一层可多子带，结构树排序决定兄弟先后；删除父带先展示所有被删子带/绑定影响，可整次撤销。表格列宽之和≤正文宽，溢出禁止发布；运行值变长靠grow/分页，不压缩成不可读小字。

CollectionBinding按mode做互斥验证：RootPath必填instanceId/path；ParentPath必填path且当前上下文有父记录；Dataset必填datasetRevisionNId/parameterMap，path为空代表结果根数组，非空指结果集合路径。数据层筛选的Row指候选集合行，取集合的ParentPath在进入候选循环前求值，不能循环中漂移。PageHeader/Footer不持有当前明细行，引用Row属于发布错误，应使用PageParam或全报告固定值。

CheckBox必须提供value绑定且禁止aggregate。运行只接受Boolean或显式空值，不将字符串"false"等强转为布尔值。true/false/null分别输出选中、未选中、未知三态；静态输出仅允许SPAN的role=checkbox及aria-checked=true/false/mixed，不扩充为可交互HTML。

设计器采用左侧控件/结构/字段、中间画布、右侧页面/区段/控件属性。页面属性提供现有七类区段插入，分组头脚成对生成互引；通用工具栏没有领域样例载入动作。属性切换不修改草稿；字段路径使用共享虚拟选择器，表格只挂载当前列，外观仅挂载当前样式。横向头/Detail/脚、条码、Gauge、PDF签章等未具备完整输出合同的能力不登记为已支持。

报表设计画布增加顶部/左侧标尺（横向从纸张边缘起算，纵向从各区段内容起点计量）、正文辅助网格、四边距阴影、尺寸箭头、边界虚线和数值。测量单位可切换 mm/cm/in/px，px 按 96 dpi 物理换算，和编辑器内部 3 px/mm 的显示比例区分；单位切换只改变标尺及边距标注，不改变文档、历史或后端合同，属性输入及保存仍使用 mm。辅助标尺与纸张同步缩放和滚动，边距变化即时更新，不进入预览/导出文件。

标尺的四个蓝色手柄可拖动页边距，保留正的正文区域；选中控件显示八方向尺寸手柄和 X/Y/W/H 读数，同一区段内按控件边缘/中心及正文边界以5屏幕像素容差吸附，显示对齐辅助线，Alt暂时关闭吸附。缩放保持对侧固定且尺寸不小于1mm；表格宽度调整同步按比例分配现有列宽。已配置的页眉/报表页眉/明细/分组/页脚等区段显示类型、名称和高度条，可点击进入属性；区段边界支持高度拖动，不小于已有控件的底部。设计态各区段紧凑顺排，页脚也紧接上一段，统一拖动下边界调整高度。画布高度为上下边距与各区段内容高度之和，不按物理纸高补空白；明细只显示一行绑定占位。左侧彩色区段栏标明上/下边距、页眉、报表页眉、分组头脚、明细与页脚等已配置区段，点击切换对应属性，不写修改历史。纵向标尺在各区段内容起点归零；下边距从画布底部手柄调整。运行及预览仍用真实纸张高度分页，设计条带不进入输出。一次指针操作仅提交一次历史，Esc/指针取消还原原草稿；拖动中暂缓自动适应画布，松手后再适配。只有交互手柄接收指针事件，网格、标注与辅助线不拦截控件。

Table默认rowMode=BandRow：每个带实例画当前行的一行单元格，columns.value的Row就是所属带当前行，控件value必须省略；无需把一条工序包装成数组。Collection模式必须value绑定数组，列Row改为集合当前行，ParentRow指所属带当前行。headerMode默认OncePerParent，在相同父实例中只输出第一次表头；repeatHeader控制该表跨物理页的续表头，两者不能混为每条明细都重复表头。空集合不会伪造一行空单元格。单报表可选Label显示无明细；电子记录组装先判业务内容为空并跳过，不能用Label占位规避“不占位置”。

flow.afterControlIds只引用同带已在上方的控件，表示“跟随这些内容的实际底部”；不可循环，设计器拖放后给出关联提示并存入配置。Overlay仅供显式固定装饰/叠印，canGrow必须false；正文HTML和明细表不能靠Overlay截断。精确位移与留白规则见运行规则§2，设计与试运行使用同一规则。

QueryReportDef=`{instanceId,resultBandId,filters:[{parameterName,label,control:Text/Number/Select/Date/DateRange/BusinessSelector,optionsDatasetRevisionNId?,valueFieldId?,labelFieldId?}],columns:[{controlId,columnId,visible,sortable}],defaultSort:Sort,defaultPageSize:20}`。resultBandId指向唯一查询结果Detail，列引用该带的Table列，非独立复制；筛选项绑定parameters声明，再通过instances映射到Dataset查询参数。控制项类型与参数类型须匹配，DateRange绑定两个Date参数或声明为二元素Array。服务器只接受登记筛选/排序列，字段授权同导出；生成全结果报告重新按固定参数/排序取完整快照，不能只导出浏览器当前一页。`POST /reports/{nId}/query`输入`{revisionNId,parameters,page,pageSize,sort}`→`{items,page,pageSize,totalCount,requestId,diagnostics}`；需要report.run及Dataset数据权限。设计试查`POST /reports/query-preview`输入`{document,parameters,page,pageSize,sort}`，返回同结构并标明样本上限。

ReportBundle document=`{schemaVersion:1,mode:Simple|ElectronicRecord,parameters,instances,paper?,items?,assembly?}`，mode创建后不可改，复制新建可换。Simple的items=`[{id,reportNId,parameterMap,enabled,required:true,startOnNewPage:true}]`，pageNumberMode=`Preserve|Global`。ElectronicRecord必须paper且assembly，禁止items的预分页拼接。

assembly=`{root:CollectionBinding,order:Sort,operation:{collection:CollectionBinding,order:Sort},rules:AssemblyRule[]}`。AssemblyRule=`{id,name,priority:int,when?:Condition,reportNId,parameterMap,content:ReportContentBinding,repeat?:CollectionBinding,presence?:CollectionBinding,required:false,emptyBehavior:Skip,headerMode:Inherit,breakBefore:Auto|Page}`。默认Auto；每工序匹配所有符合规则，按priority+id稳定排序；每规则可0..N实例。report的pageheader/footer在电子记录中由母版替代，只保留正文/报表首尾内容；循环数据上下文固定在每实例，不共享可变全局row。

repeat有值时，该集合就是有无数据依据（presence必须省略），每行生成一个实例；只需每工序输出一份合并子报告时省略repeat、必填presence集合，非空生成一实例、空则跳过。presence与repeat均相对实际工序/数据快照求值，不能以固定页头、工单基本信息或“无明细”标签判断子报告有数据；required=true且空报DATA_REQUIRED。此配置明确显示为“有数据依据”和“逐条重复 / 本工序一份”，禁止两字段都省略让实现自行猜测。

ReportContentBinding=`{mode:WholeReport|BandSubtree,entryBandId?,rowMap?:[{targetPath,source:Binding}],ancestorMap?:[{bandId,source:Binding}]}`。WholeReport用parameterMap调用完整子报告正文；BandSubtree从可选Detail带开始，仅输出该带及其后代，不输出祖先正文/其他兄弟/报告首尾。rowMap将当前来源行映射到该带的行Schema，可直接映射对象/子集合，不仅是标量；该入口行已由组装提供，不能再次执行入口带原来的集合查询导致工单或明细成倍重复。子带仍沿自己的ParentPath/Dataset配置展开。

组装映射求值时：Row为repeat当前记录（无repeat时为当前工序），ParentRow为当前工序，Root为当前工单。进入子模板后，Row为映射后的入口行；外部祖先上下文由ancestorMap按原bandId补齐，至少含被ParentRow/Root/contextBandId引用的祖先。没有引用的祖先可省略；缺必要祖先报绑定错误，不偷偷使用上一个工单。祖先仅供绑定，不输出正文。不同模式的无效字段拒绝发布。`GET /reports/{nId}/binding-contract?revisionNId=…`返回`{parameters,entryBands:[{id,name,parentBandId,rowSchema,requiredAncestorBands}],revisionNId}`，供选择器及字段映射表使用；必须有模板Design权限，发布固定对应修订。

### 8.3 Workbook与Office适配

2026-10-30增补（工作副本与手动历史）：日常保存更新当前工作副本，`contentVersion`仅为WOPI及CAS使用的内容修订；展示的`historyVersion`仅在手动“保存版本”时递增。`hasWorkingCopy`表示当前内容尚未归入历史，不等于Office存在未保存修改。首次导入保留历史1；旧历史逐版保留。编辑器依据已校验source/origin的`Doc_ModifiedStatus`与`Action_Save_Resp`确认保存，确认成功后关闭不再无条件提示；仍有修改可“保存并离开”，失败保留编辑器。

工作副本替换在同一保存事务登记旧文件回收队列；一分钟读票据宽限后复用Files释放引用、保留策略与删除流程。历史和冲突恢复文件不进入该队列。保存版本与内容提交使用同一数据库行锁，跨进程保持顺序；会话同时核对base行和base内容修订，避免工作副本主键不变时覆盖旧写入。独立Office部署和平台协议边界保持原约定。

会话响应另含`accessToken/mode/supportsTokenRefresh/slidingSession`。编辑使用全屏工作区，不设置固定编辑总时长。`slidingSession=true`时向Office提交`access_token_ttl=0`并后台保持续期；`POST /workbooks/{nId}/sessions/{sessionNId}/renew`返回`{accessToken?,expiresOn}`，通过当前平台登录与原执行身份复核后更新15分钟滑动租约和身份快照。`supportsTokenRefresh=false`仍可续期，只保留原token hash并返回`accessToken=null`，浏览器不重载Office；true时允许已核验的票据轮换。关闭/撤销/过期会话不能续期，归档后不能延长写会话。

`POST /workbooks`请求`{name,sourceFileNId?,sourceArtifactNId?}`（二选一）→WorkbookDto；`GET /workbooks`列表；`GET /workbooks/{nId}/versions`版本列表；`POST /workbooks/{nId}/sessions` `{mode:Edit|View,baseContentVersion}`→`{sessionNId,editorUrl,expiresOn,contentVersion}`；`POST /workbooks/{nId}/sessions/{sessionNId}/close`；`GET /workbooks/{nId}/versions/{versionNId}/content`；`POST /workbooks/{nId}/archive`携双版本。

保存内部端口 `CommitWorkbookAsync(sessionNId,baseContentVersion,saveOperationKey,Stream,ct)`返回`{contentVersion,fileNId,sha256}`，409时`{currentContentVersion,recoveryFileNId}`。编辑服务只持短期文件/会话票据，不取得平台登录令牌；File仍扫描并授权。

OfficeProvider接口固定`CreateSession/CheckFileInfo/GetFile/Lock/RefreshLock/Unlock/PutFile/CloseSession`，适配实现优先验证WOPI，锁/授权/内容版本仍归Studio。首版不承诺多人同时合并编辑：同一工作簿一个有效写锁，第二人只读或创建分支副本，保存CAS验证；不能丢失另一人的已保存值。新增自有表见数据模型，不拿上传WriterEpoch当文档版本。

具体Office发行包尚未准入，不能将CODE、AGPL产品或商业插件未经评估打进默认开源发行；但接口、版本、冲突与验收已固定，不能用选型未定删除在线Excel首期范围。引擎验证与准入见页面验收§8。

### 8.4 WOPI协议面（Office适配内，非浏览器业务 API）

PutFile复用正式报表的通用文件确认方法，在同一次请求内等待同一上传的扫描/引用确认（最多30秒），不因正常短暂Pending立即返回503。确认后复核会话、权限、锁和原base版本再提交；超时/失败不能返回假成功，仍保留503与Retry-After及旧版。Office会话委托租约独立于当前JWT剩余时长，仍保留来源平台会话撤销/安全版本/权限复核；持续续期不能复活已过期的Office会话。

新增`/office/wopi/files/{sessionNId}`：GET=CheckFileInfo；POST根据`X-WOPI-Override=LOCK/REFRESH_LOCK/UNLOCK/GET_LOCK`处理；`/contents`的GET=GetFile、POST+Override=PUT执行PutFile。协议响应按WOPI原生JSON/流/头，不套平台ApiResult；其他Studio API仍套标准信封。未知Override返回501，锁不匹配409并带当前`X-WOPI-Lock`，过期令牌401，无权文件404。

CheckFileInfo返回`BaseFileName/OwnerId/UserId/Size/Version/UserCanWrite/SupportsLocks/SupportsUpdate`及受控界面能力；Version为contentVersion字符串，Size是WOPI协议允许范围内有界整数。只读会话UserCanWrite=false，服务端仍拒绝写。令牌绑定session/user/tenant/workbook/模式/audience，不接受query伪造用户。入口和反代访问日志必须屏蔽access_token。

PutFile校验锁和base版本→读取有界流并计算hash→以session+baseVersion+baseContentVersion+contentHash派生saveOperationKey；重复相同已确认内容返回已保存修订，不新增历史。成功更新工作副本和此会话base内容修订，返回`X-WOPI-ItemVersion`；409保留恢复文件、不给编辑器假成功。锁原值仅加密保存以满足冲突响应，hash用于比较；锁长度超过协议限额拒绝。具体Office Provider必须完成真实CheckFileInfo/锁/读取/多次保存/重开一致性测试，浏览器里只放一个假Excel表格不算通过。

### 8.5 公共文件传输门面

所有Studio页面调用相同`/api/v1/studio/files`前缀，由IStudioFileTransfer分派Platform/Embedded；不在独立前端写死SystemData地址。契约直接复用[FileContracts](../../../src/backend/src/Services/SystemData/IndustrialPlatform.SystemData.Contracts/Files/FileContracts.cs)和[FilesController传输协议](../../../src/backend/src/Services/SystemData/IndustrialPlatform.SystemData.Api/Controllers/FilesController.cs)的指定子集：`POST /upload-sessions`、`GET /upload-sessions/{sessionNId}`、`PUT /upload-sessions/{sessionNId}/content-hash`、`POST /upload-sessions/{sessionNId}/resume-proof|resume|pause|cancel|complete`、`HEAD/PATCH /uploads/{transportId}`、`PUT/DELETE /{fileNId}/references/{referenceNId}`、`GET /{fileNId}`、`GET /{fileNId}/content`。竖线表示分别登记的动作路径，不是URL字面量；不新增全租户会话/文件管理列表。续传头、offset/WriterEpoch、hash、流式正文和错误码沿原合同，路径和Location改由Studio公共前缀生成。Studio JSON边界的Int64 Length/Offset按§1序列化十进制字符串；适配器转换既有File DTO，上传协议头保持其原字符串语义，WriterEpoch依实际类型校验；不修改旧File公开协议。读取内容同时校验个人引用，业务owned内容仍走所属资源端点，不混用。

外部模式以当前已验证Studio主体调用相同文件应用实现；原生以受信适配调用既有公开File能力并检查平台File权限。上传入口新增`usage={moduleKey,resourceNId?,purpose:LedgerField|TemplateAsset|WorkbookImport|TemplatePackage}`，由服务器核对已启用模块、对应Design/ledger.write/workbook.edit权限和资源范围并固化至服务端上传上下文，浏览器不能改owner/tenant。已有File Purpose存规范化用法键，资源依据放受控metadata（上传记录新增`owner_context_json:json(8)?`，旧平台上传保持null，Studio上传必须有；File下一新迁移追加，Embedded固定STF-001首次DDL包含此列）。后续每步按同一上下文重验；Files.Disabled时返回503 `STUDIO_FILES_UNAVAILABLE`，不会临时改用平台文件地址。

IStudioFileTransfer的`CreateScopedSession(context,request,usage)`是新增受信应用入口；其余操作映射上述现有方法，不能把owner_context作为浏览器可写字段透传。Platform同进程调用该公开端口；分进程新增`/internal/v1/files/studio-transfer`同后缀的限定门面，沿§8受信签名/逐动作白名单，仅platform-studio可调用，禁止注册整个File管理API给服务调用。旧File API/权限/上传不变。owner_context固定`{producerServiceKey,moduleKey,resourceNId?,purpose,actorUserNId,tenantNId}`且每次验证不可变；模板包和新工作簿未有resourceNId时按拥有者及模块权限约束。

§4低代码仍使用个人引用语义，其他人查看台账不会自动取得附件权限；§8.1的业务owned引用用于模板资产/报告/预览/工作簿。此门面由PF08-001实现并验证真实公共上传控件的注入端点，005/006消费，不能拖到PF09-009；跨用户文件分享仍按现有File授权合同，不在本轮新建共享盘。

```json
  "revisionNId":"REV-LINE-3",
  "parameters":{"lineCode":"L02"},

  "pageSize":20
}
```

对应Data负载：
