# PF06 数据字典、接口与页面规格

版本V1.0；2026-09-07；对应实施09。待派遣；生产就绪度仍受双PoC门禁阻塞。


## 1. 类型、命名与基线

这是派遣输入的设计规格，不是已建表证据。服从[派遣前规则](../STANDARD-派遣前详细设计与页面验收.md)和[实施模板](../TEMPLATE-开发实施方案.md)。表中 `?` 表示允许 NULL；未标 `?` 均 NOT NULL。没有默认值的字段必须由经过校验的用例赋值，不由数据库猜测业务默认。

| 类型代号 | .NET / PostgreSQL / SQLite / JSON | 约束 |
| --- | --- | --- |
| id | Guid / uuid / TEXT / 不对外 | 内部主外键；应用生成；SQLite 存规范 GUID |
| key | string / varchar(128) / TEXT / string | 1～128，身份源标识保持原值；SQLite CHECK 长度 |
| nid | string / varchar(64) / TEXT / string | 本服务生成 Guid 的 N 格式32字符；不采用数据库 Id 对外 |
| str(n) | string / varchar(n) / TEXT / string | SQLite 同样限制最大 n 字符；空串是否允许见字段 |
| text | string / text / TEXT / string | 长度、敏感性在字段规则中声明 |
| i32 | int / integer / INTEGER / number | 范围逐字段指定 |
| i64 | long / bigint / INTEGER / 十进制 string | 序号/版本/字节数不经 JS number；JSON 样例 `"42"` |
| time | DateTimeOffset / timestamptz / TEXT / string | UTC RFC3339；SQLite 固定 UTC 格式比较，业务时间注入可控时钟 |
| bool | bool / boolean / INTEGER / boolean | SQLite CHECK 0/1 |
| hash | string / varchar(64) / TEXT / string | SHA-256 小写 hex，64字符；哈希不代替授权 |
| json | 已声明 DTO / jsonb / TEXT / object | schemaVersion=1，禁止任意无 schema 扩展；≤256KiB，单独注明者例外 |
| dec(p,s) | decimal / numeric(p,s) / TEXT / 十进制 string | SQLite 保存规范十进制文本，应用精度校验，不走 REAL |

逻辑字段转换为同名 snake_case：NId→n_id、TenantNId→tenant_n_id、CreatedOn→created_on。下面每行给出精确物理名。跨服务引用只是 string，不建外键；本服务自行签发的 NId 不要求外部 Identity/File 改其命名或大小写。若前置实际标识超出128，先改规格和测试再派遣，不静默截断。

**E 基组：** 领域实体表统一含下列字段，逐表不重复展开；技术表显式列字段，不套软删除/双版本。

| 逻辑字段 / 物理列 | 类型 | 默认与规则 |
| --- | --- | --- |
| Id / id | id | PK，Guid.NewGuid，无数据库业务默认 |
| IsFrozen / is_frozen | bool | false；普通修改保护 |
| IsLocked / is_locked | bool | false；锁定保护 |
| IsDeleted / is_deleted | bool | false；不等于消息撤回/打印取消 |
| EntityType / entity_type | text | 完整领域类型名，服务生成，不开放编辑 |
| CreatedOn / created_on | time | 创建时 UTC，应用赋值 |
| LastUpdatedOn / last_updated_on | time | 初始与 CreatedOn 相同；实际改变才更新 |
| OptimisticVersion / optimistic_version | i64 | 初始0，实际改变+1；API用字符串 |
| ConcurrencyVersion / concurrency_version | id | 初始非空，实际改变重新生成；API若暴露为GUID字符串 |

**B 基组：** 本文全部领域实体另含 `NId/n_id:nid` 和 `TenantNId/tenant_n_id:key`，必须 UQ(tenant_n_id,n_id)，包括已软删除行。子实体继承本地父租户，用例校验同租户，不能接受客户端提供租户。表的 E/B 组加逐表字段就是完整字段集合。可变命令使用 expectedOptimisticVersion:string + expectedConcurrencyVersion:GUID，两者匹配；幂等已完成语义先返回原结果，避免重试变409。

技术表以具体 PK/UQ 为准；领域 FK 使用普通父 Id、ON DELETE RESTRICT，不创建软删除影子列。关键冗余 NId 只读映射、同事务赋值并验证，不提供单独修改入口。所有租户查询先带 tenant_n_id，后台任务逐租户取受限上下文。状态值保存在 varchar 列并设 CHECK；未知值失败关闭，不以整数枚举顺序作持久协议。

## 2. RemoteAssistance持久化

Schema=`collaboration_remote_assistance`，SQLite前缀=`collaboration_remote_assistance_`；由实施09已约定独立初始化单元拥有，不挪用Messaging仓储。表名保留原remote_assistance_*。领域对象E/B基组不再重复。Session/Invitation/Grant属于同聚合；票据/租约/观察是技术记录。

### 2.1 remote_assistance_session

领域实体，完整字段=E+B基组+下表。

| 逻辑字段 / 物理列 | 类型 | 默认、约束与用途 |
| --- | --- | --- |
| ConversationNId / `conversation_n_id` | key | 初始来源，跨Messaging无FK，不能授权额外Viewer读原聊天 |
| SharerUserNId / `sharer_user_n_id` | key | 唯一共享者 |
| Reason / `reason` | str(500) | trim后1～500 |
| State / `state` | str(24) | Draft / Invited / Accepted / Connecting / Sharing / Suspended / Declined / Expired / Cancelled / Terminated |
| EngineKind / `engine_kind` | str(32) | Screego / NativeSignaling；生产值由双PoC决定，不允许前端任选引擎 |
| NetworkPolicy / `network_policy` | str(24) | Auto / RelayOnly；由部署策略约束 |
| ExpiresOn / `expires_on` | time | 创建后30分钟上限，部署可缩短 |
| StartedOn / `started_on` | time? | 首次Sharing时设置，重连不重置 |
| EndedOn / `ended_on` | time? | 终态时间 |
| EndReason / `end_reason` | str(64)? | Cancelled / Declined / Expired / SharerStopped / AdminTerminated / ReconnectTimeout / IdentityRevoked |
| ReconnectDeadlineOn / `reconnect_deadline_on` | time? | Suspended后60秒，超过则终止 |
| LastActivityOn / `last_activity_on` | time | 服务端受权心跳，不采信客户端时钟延长 |
| RequestNId / `request_n_id` | nid | 创建幂等 |
| RequestHash / `request_hash` | hash | conversation+sharer+排序viewer列表+reason+策略 |

UQ(tenant_n_id,sharer_user_n_id,request_n_id)；IX(state,expires_on)。共享者活动会话部分UQ(tenant_n_id,sharer_user_n_id) WHERE state IN(Draft,Invited,Accepted,Connecting,Sharing,Suspended) AND NOT is_deleted，禁利用软删除绕过活动状态。角色人数在持锁事务内限制1～3，不是先count再无锁插入。

### 2.2 remote_assistance_invitation

领域实体，完整字段=E+B基组+下表。

| 逻辑字段 / 物理列 | 类型 | 默认、约束与用途 |
| --- | --- | --- |
| SessionId / `session_id` | id | FK session.id |
| InviteeUserNId / `invitee_user_n_id` | key | Viewer主体 |
| DeliveryConversationNId / `delivery_conversation_n_id` | key | 该Viewer与Sharer的个人会话，跨模块无FK |
| Role / `role` | str(16) | 固定Viewer |
| State / `state` | str(16) | Pending / Accepted / Declined / Revoked / Expired |
| IssuedOn / `issued_on` | time | 服务时间 |
| ExpiresOn / `expires_on` | time | min(签发+120秒,session.expires_on) |
| RespondedOn / `responded_on` | time? | 初始NULL |
| ResponseReason / `response_reason` | str(500)? | 拒绝可选，不用于权限 |
| CardContractVersion / `card_contract_version` | i32 | 固定1 |

| UserNId / `user_n_id` | key | Sharer或Viewer |

### 2.7 可靠投递与初始化

remote_assistance_outbox/inbox采用[PF05细化规格](PF05-数据接口与页面规格.md)§2.10完整字段与类型（本单元内表名替换，ModuleKey=remote-assistance），复用模式而非ReferenceData具体受限表；仅真实Messaging/Audit/Identity消费者注册。邀请投递Payload包含InvitationNId/DeliveryConversationNId而非聊天原文；发布前验证仍有效。Session终止、Grant撤销、票据/租约撤销与可靠撤权通知同事务，外部引擎调用不放事务中。所有状态命令按Session→Grant→Ticket→Lease锁顺序，拒绝反向锁；消费检查Session终态和GrantEpoch在同事务内。

本独立初始化单元的`remote_assistance_schema_migrations`/`remote_assistance_seed_ledger`采用PF05§2.10的明确服务账本字段，命名空间归本单元，保留实施09已定义表名；预定migration `remote-assistance-1.0-001`设施、002领域/租约/观察，seed `remote-assistance.baseline/permissions/navigation`首版1.0.0，实际产物生成后计算checksum。G06-2核对PF05最终交付注册与版本冲突后登记，不虚构已存在的迁移产物。

## 3. 明确请求、状态与媒体授权

外部`/collaboration/api/v1/remote-assistance`、内部`/api/v1/remote-assistance`。长版本为十进制字符串。以下数据均在ApiResult.data内，角色/主体来自受信上下文。

| 编号/Method 相对路径 | 请求字段 | 响应/规则 |
| --- | --- | --- |
| A06-01 POST sessions | requestNId:string32,conversationNId:string,viewerUserNIds:string[1..3],reason:string<=500 | {sessionNId,state,invitations:[{invitationNId,inviteeUserNId,state}],双版本}；session.create；Viewer去重、本人/跨租户拒绝 |
| A06-02 GET sessions/{nId} | 无body | {sessionNId,state,role,sharerDisplayName,expiresOn,myGrant:{grantNId,epoch,state},participants:仅允许显示的姓名/角色/状态,双版本}；不含原聊天/凭据 |
| A06-03 POST sessions/{nId}/accept | invitationNId,requestNId,clientNonce:base64url32字节 | {sessionNId,state,grantNId,grantEpoch,joinTicket?:string,expiresOn?}；本人邀请；原票据仅首次返回 |
| A06-04 POST sessions/{nId}/decline | invitationNId,requestNId,reason?:string<=500 | 本人Invitation状态；幂等，不终止其他Viewer |
| A06-05 POST sessions/{nId}/cancel或terminate | requestNId,reason:string<=500,双版本 | 当前Session安全状态；cancel仅StartedOn为空的非终态会话发起者，已共享后用terminate；terminate为Sharer或独立管理员 |
| A06-06 POST sessions/{nId}/leave | requestNId,双版本（自己的Grant） | 自己Grant Revoked；其他Viewer继续 |
| A06-07 POST sessions/{nId}/join-tickets | requestNId,clientNonce,expectedGrantEpoch:string | 新票据一次返回+epoch；先撤销旧票据/租约；重试同请求只返回安全状态 |
| A06-08 POST join-tickets/exchange | ticket:string<=256,clientNonce:string<=128,connectionNId:string32 | {leaseNId,grantEpoch,expiresOn,engineAccess:受限一次授权,iceServers:短期配置}；主体与票据匹配，消费一次，响应禁止缓存/日志 |
| A06-09 POST sessions/{nId}/heartbeat | leaseNId,connectionNId,grantEpoch:string | {expiresOn,state}；每10s，服务器时钟续租；未知/撤销立即失败 |
| A06-10 POST sessions/{nId}/participants/{userNId}/revoke | requestNId,reason,双版本 | 该Grant安全状态；participant.manage；只能撤Viewer不换Sharer |
| A06-11 GET sessions/{nId}/diagnostics | 无body | §2.6聚合+TraceId，diagnostics.read；不含地址/媒体 |

附加管理列表GET `/sessions?state=&fromOn=&toOn=&pageIndex=1&pageSize=30`，pageSize≤100，最多查询31天，排序createdOn desc,nId desc；管理权限`remote-assistance.session.read-all`与诊断权限分开，不给普通Viewer提供全量名单。

```json
{"requestNId":"41bed0c42a7449ab93a2d7b33b7f7e8d","conversationNId":"ab487e22bc094bd1ab75b6d05bc79698","viewerUserNIds":["viewer-a","viewer-b"],"reason":"检查设备页面"}
```

示例拒绝：viewer-b不在可信可见目录→404，不能先创建对viewer-a的半条会话。接受成功但响应丢失：先A06-02查自身Active→A06-07新request/nonce补发，旧epoch消费/续租失败；不得从TokenHash推算原Secret。错误码采用实施09 §7.5；输入400、不可见404、版本/同键异义409、过期410、引擎不可用503，并携带安全恢复动作。

媒体协议外壳固定`contractVersion=1,sessionNId,senderGrantNId,targetGrantNId,messageNId,sequence:string,type,payload`。业务命令身份不采信sender字段，服务端回填；Offer/Answer/ICE只发给明确有效targetGrant，禁广播整个原聊天组。Payload≤64KiB、每连接常规信令≤30条/s（短时burst60），超限稳定拒绝。具体Hub/WSS路径、Cookie/首帧认证适配由双PoC结果写回，生产未冻结不得实现“通用任意代理”。

| 状态迁移 | 条件/副作用 | 禁止行为 |
| --- | --- | --- |
| Invited→Accepted | 首个Viewer接受，邀请+Grant原子更新 | 单人拒绝终止全部 |
| Connecting→Sharing | 有有效媒体连接/可观察新帧 | 仅收到API200即Sharing |
| Sharing→Suspended | 最后Viewer失联，60s恢复窗口 | 自动重新捕获结束的屏幕轨 |
| Invited→Declined/Expired | 无人接受且全部Invitation已拒绝则Declined；全部过期或拒绝/过期混合则Expired | 单个邀请拒绝/过期终止仍有效的其他邀请 |
| 未Sharing且未进入过Sharing的会话→Cancelled | 发起者主动取消，所有邀请/Grant/票据撤销；与运行终止区分 | 已共享后用cancel伪装从未开始 |
| 任意非终态→Terminated | Sharer/管理员显式终止、身份撤销或运行/恢复超时，逐Grant撤权；单纯邀请等待过期按上一行Expired | 只改数据库状态不停止媒体 |
| Viewer leave/revoke | 关闭该PeerConnection、停对应播放 | 停全体共用捕获轨 |
