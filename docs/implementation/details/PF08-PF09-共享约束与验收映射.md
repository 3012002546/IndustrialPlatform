## 2. 已确认的产品边界

| 部分 | 本期必须交付 | 实现约束 |
| --- | --- | --- |
| 工作台与部署 | 四个独立菜单；管理列表、设计、试运行、返回；平台原生、独立部署、完全离线、外部 MES 接入 | 平台内原生复用框架及Identity/ReferenceData/File/Audit/Scheduler，契合度优先；剥离后由适配层接现有MES，不强制安装这些平台服务。四部分共用 `PlatformStudio.Service`，核心及授权/恢复语义一致 |
| 低代码 | CRUD 独立页面、组合页面、注册代码组件 / 页面；自有辅助台账；字段、动作、参数可配置并试运行 | 业务写入通过所属业务的注册 API；不跨模块写业务表、不开放任意后端脚本，不把 ReferenceData 当台账存储 |
| 看板 | 单页自由画布、工业图形和图表、页面共享数据、组件多属性绑定、列表行跳转、目标参数到查询条件的配置、轻量轮播 | 1920×1080 是画布默认值，可修改；工作台适配平台框架。一个页面接口可服务全部组件，也可使用多个命名实例；轮播不是多页设计器 |
| 单报表 | 查询 / 固定格式；等宽的主从明细带；按实际集合展开；字体、字号、颜色、表格和 HTML 绑定 | 层级数量由配置确定，三级仅为样例；数据层级不缩窄正文宽度。设计器显示绑定路径、父行上下文、字段类型及样本 |
| 简单组合 | 选择独立报告、参数、顺序、页码策略后组合输出 | 单报表保持独立可用；保留或统一页码需有明确策略，不叠印 |
| 电子记录组合 | 工单 → 实际工序 → 实际存在的子报表；嵌套 / 重复 / 排序；HTML、人工记录、系统操作及来源；紧凑分页 | 子报表种类和数量可变；无数据不占位，取数失败不能当空数据；前页未满继续排。整份由主模板统一横向或纵向，统一页头、页脚和最终页码 |
| 在线 Excel | 上传或从报表产物建工作副本；浏览器编辑、保存、重开、下载、内容版本与冲突处理 | 首期支持；不能以普通 xlsx 导出代替。修改工作簿不自动改业务源；选型与发行权限仍须核验 |
| 追溯 | 多行业模型；起点数据、搜索项 / 列、节点明细、边的查询逻辑可配置；节点 / 连线拖拽；任意节点正反向展开 | 从库存、工单及实际业务事实取数；半导体链仅为示例。图形位置不是业务事实；明细链接 / 文件在当前页模态框查看 |

共同设计操作为：拖拽组件 / 报表块 / 节点和连线、选择、平移、缩放、适应画布、撤销 `Ctrl+Z`、恢复 `Ctrl+Y`、返回上一级并保留草稿、收起 / 展开侧栏。输入框内优先保留原生文本撤销。报表纸张尺寸与方向属于模板，不能随工作台缩放改变。

“行业内最优解”在本清单中落实为：常规配置无需改源码，绑定可观察、错误可定位、操作可恢复、结果可核对、部署和许可可交付；不据此扩入通用工作流、规则引擎、知识图谱平台或生产工单录入模块。

## 5. 验证与回写原则

实施11/12分别维护任务状态、依赖、完整九字段卡和执行记录；本页不复制任务清单。需求变化更新§2，前置证据更新§3，断言/任务映射更新§4及页面规格B表，并同步主文引用。四部分按C1～C4各留验收结论，不能只回写一个PF09完成状态。

绑定、递归展开、分页不重不漏、越权与幂等需要可重复证据；布局、拖拽、缩放和返回需真实浏览器与约定客户端。源码变化按仓库新鲜Release构建后测试；文档整理只查链接、编号、依赖、覆盖与diff。

开发与A/PS验收没有因文档调整完成，候选PoC与真实MES接入未执行。平台许可证未定，DevExpress等只借鉴产品思路，不复制受限实现或资产。
