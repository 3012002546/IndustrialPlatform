### 当前缺口与职责边界

- 选择模型曾通过 query 变化打开新工作台标签，且 RouterView 以 fullPath 为 key 重建页面。修正为追溯执行显式声明 query 属于页内状态，固定标签身份、保持同页实例、更新标签恢复地址；兼容旧链接并归并历史重复标签。其他路由默认规则保留。
- 模型设计的是“对象类型与取数关系”，执行图显示的是“具体业务实例与事实”。设计页坐标不能直接当执行图实例坐标：一个对象类型可以产生多个实例，执行图还允许分叉、合流和事实环。
- 当前执行投影仅横向自动布局；已有单节点主明细数据集、字段、多个带参数链接及附件配置，点击节点会读取明细，但尚无多个独立、可分页的关联明细表。主明细服务要求完整身份严格匹配唯一行，不能把多条检验项直接塞进该唯一行合同。
- 当前外链仅支持登记来源的模态嵌入；内部已发布报表/低代码资源不是已有的独立链接类型，不能宣称任意业务页都能配置。2026-11-02 用户确认目标交互为“默认近全屏模态框，用户主动选择新浏览器标签页”；这是待实现的统一链接行为，不新增平台工作台标签。

### 建议配置与交互

1. 模型新增运行展示配置：默认布局 `LeftToRight` 或 `TopToBottom`。执行页允许临时切换，只重排当前结果、端口方向和边路由，不重新查询、不改关系箭头、不写回模型；新查询采用当前会话选择，换模型采用该模型默认。旧模型缺省横向。布局方向与 `Upstream/Downstream/Both` 查询方向独立。横竖模式均须验证多父、多边、环、跨层边与大图预算。
2. 保留节点唯一主明细，用于核验身份并提供可信上下文。新增有序 `detail.sections[]`，每组可配置稳定 id、名称、展示方式（字段/表格）、已发布数据集修订、参数映射、集合路径、字段或列定义、行键及分页大小。分组名称和数据集由实施配置，不内置 IQC、IPQC、批记录枚举。
3. 点击节点在当前执行页打开详情区域，按模型配置显示分组 Tab；首组加载，其余按需加载并支持局部重试。表格采用平台 AppDataTable 的分页/列定义，不在每个图节点内铺大量明细。切换节点或模型取消旧请求，迟到响应不得覆盖当前分组。
4. 链接动作配置独立于字段：名称、目标类别、目标登记键或已发布平台资源、参数映射。按 2026-11-02 用户确认，默认在当前页打开接近全屏的模态框（桌面以约 96vw × 92vh 为基准，保留边距及标题栏）；标题栏显示链接名称、“在新浏览器标签页打开”和关闭按钮。只有用户主动点击才打开新的浏览器标签页，不自动弹出、不新增平台工作台标签。新页保留同一业务目标、参数和模型修订；打开后原模态框保持，关闭模态框后原图谱、缩放、节点选择及详情 Tab 保持。目标拒绝嵌入时在模态框提示，并仍提供经授权的独立打开入口；权限失败或读取凭证失效不能借此绕过。内部平台资源复用可独立访问的内容宿主，避免在模态框内再套完整平台外壳；文件另行签发/使用可在新页访问的授权预览入口，不能直接复用依赖当前页面 Bearer 的下载地址，也不能因关闭原模态框而破坏已打开的新页。现有外链/文件保持兼容；平台资源链接需要补齐宿主能力、资源版本和参数校验后才开放。节点链接以可信主明细行绑定；若需要从某条检验结果打开报告，必须通过明细分组的稳定行键由服务端重取授权行，不能相信浏览器传来的行对象。
5. 示例配置：原料节点“来料检验”表格把主明细的 `materialCode`、`materialBatch` 映射到检验数据集参数；母液/半成品/清洗节点可配置“过程检验”，以 `physicalBatch` 等业务字段映射；半成品/成品可另配“关联工单”表格及“批记录”链接。实际字段名、参数数目、标签和对象适用范围均可配置，不能从显示名称推断业务。
6. 关联检验表和链接属于节点详情，不默认产生物料谱系边。只有客户明确要将检验记录作为图上的对象时，才另配对象及 `Context` 关系，避免把检验项混进投料、产出、数量平衡或递归传播。

### 服务端与发布约束

- 建议新增节点明细分组查询，浏览器只传模型修订、nodeKey/nodeToken、sectionId 和分页/允许排序；服务端重新确认模型修订、节点权限、主明细唯一行，并计算分组参数。禁止浏览器指定任意数据集、SQL、域名或裸行上下文。
- 必填关联键缺失时显示“缺少关联条件”，不得退化成无条件查全表。工厂/租户来自可信上下文；节点 businessKey 继续承担唯一身份，物料编码、物料批次、物理批次是可独立绑定的业务字段，不要求用字符串拼接替代参数映射。
- 发布时校验分组 id、数据集修订、参数类型/必填、字段与集合路径、行键、目标能力和链接参数。发布后的布局默认值、明细分组和链接均随同一模型版本固定；旧模型兼容为现有主明细与链接，不静默改写草稿。
- 模型选择、起点选择、图谱查询、详情分组和链接请求是不同生命周期。只查可执行模型；选模不自动查谱，确认起点不自动查谱；加载图谱后才查询事实。刷新模型列表不主动清空有效图谱或切换已加载修订；模型失效、权限变化则取消并清空依赖状态。
- 验收必须同时覆盖横/竖布局结果等价、两种不同配置模板、多条检验项与分页、复合参数、空关联键、旧响应、跨工厂拒绝、链接目标授权及旧模型回归。真实 IQC/IPQC/批记录系统尚未接入，不能用演示数据证明现场联调通过。

## 4. 报表、高级控件与优化范围

### 4.1 已有能力与新增需求分开

PF-09 工作包当前记录已包含单报表、简单组合、电子记录、连续分页、正式任务/产物与在线 Workbook 的开发能力。近期证据包括表格编辑/合并、标尺/边距、紧凑区段、默认排序、生成重试防重、迟到响应、长表续页表头及 Office 连续保存。新会话应保留这些结果，核对目标缺口后优化，不从空白重新实现。

未关闭项包括极端合并/嵌套布局、完整富文本 XLSX、真实 MES 组合边界、部分跨部署/数据库矩阵、生产离线发行和本次新增高级功能。人工验收暂缓与某项开发自测通过分别记录，不能互相覆盖。

### 4.2 预览与十类导出

预览要求：单页/全部页查看、首页/上一页/下一页/末页和页码跳转、比例/适应页宽/整页、当前页快速搜索及命中定位、打印全部与当前物理页。大量页面按需显示；缩放不改变最终纸张。当前页搜索是平台要求，不能把参考控件的整份搜索直接当成完成。

导出范围完整保留：**PDF、XLS、XLSX、RTF、DOCX、MHT、HTML、文本、CSV、图像**。原口述 DOCS 按截图确认是 DOCX；图像格式、分辨率和多页打包需明确。已有 PDF/HTML/XLSX 链路不代表其余格式可用，也不能只改扩展名。

固定版式导出、表格数据导出、用户临时编辑后下载分开定义。每项明确页/行范围、类型、筛选、资源内嵌和可编辑程度；形成“控件 × 格式”的原生结构/静态呈现/不支持矩阵。

### 4.4 共同优化项

- 排版：长中文、超长行、跨页合并、重复表头、组尾、页眉页脚、混合方向；设计视图、预览和正式生成使用一致的布局规则。
- 数据：判空、分组、汇总与子报告共用本次采集结果；固定根/子模板与查询修订、排序和资源版本；不同来源的时间不能伪装成同一事务快照。
- 性能：属性按选中加载，辅助查询不阻塞画布；避免大字段列表和多页结果无界挂载；先定位取数、展开、排版或渲染的成本。
- 生命周期：直接设计预览返回 HTML，不自动创建 Jobs/Files 归档，也无固定预览有效期；正式生成继续走发布修订、幂等任务、取消/Unknown 核对和文件确认。
- 输出可靠性：中文字体与再分发、离线资源、输出峰值和工作目录回收；不能删除执行状态不确定的活动资源来假装释放成功。

## 5. 临时查询表格与 Excel 内核

### 5.1 用户最终业务要求

**进入某报表入口 → 加载空模板 → 查询填充 → 筛选、排序、临时编辑和格式调整 → 下载或打印 → 重查替换或退出释放。** 车间流水只是一个例子，未来有很多报表入口和多人同时使用。

“隔离”默认是每用户每页面独立的内存编辑状态，不是每次查询复制一个服务器文件。模板可共用只读版本；查询结果、撤销历史、筛选与编辑状态不能跨用户或页面共享。重复查询替换当前代次，缩行/零行清除旧尾行；所有结果列默认提供筛选。

正常关闭查询页销毁实例、请求、订阅及输出资源；还要覆盖工作台标签、KeepAlive、注销、崩溃、乱序响应和取消后迟到结果。浏览器退出事件不是可靠的服务器清理保障，因此常规查询不生成服务端工作簿。必要输出任务另有硬配额、超时和异常回收。

临时修改默认不回写原业务数据、不自动保存 Workbook 或历史版本、不自动上传快照，也不自动成为正式批记录。已有持久化 Workbook 的保存/留版继续遵守原生命周期。

### 5.2 技术方向

Univer 开源核心承担编辑与计算；平台掌握模板、字段绑定、查询代次、权限和输出语义；ExcelJS 写出 XLSX，FortuneExcel 作为开源转换参考。长期优先直接映射 Univer → 平台适配 → ExcelJS，不为下载常驻第二套 FortuneSheet 编辑器或中间工作簿。

优先通过公开 API、插件和宿主二开，避免修改内核。XLSX 交换与打印不因为采用 Univer 自动具备；官方 Pro 与自建适配分开。FortuneSheet 保留替代候选，Collabora 继续承担既有持久化文档用途和复杂文件对照。

适配重点：值与类型、样式 ID/对象/默认值、富文本、共享/跨表公式及缓存、合并/尺寸/冻结、多 Sheet、图片、验证、条件格式、Table、筛选条件与隐藏行。导出前提交编辑、等待当前代次计算、捕获一致快照。结果值导出和保留公式导出分开，自定义业务函数不能直接假定 Excel 可执行。

平台自有代码选择 MIT 的空间保留；第三方 Apache/MIT 声明、修改标记和适用 NOTICE 随实际交付保留，商业包不混进默认开源构建。具体来源、版本边界和许可证依据见整体说明 §2.3、2.5、2.6；本轮没有修改平台 LICENSE。
