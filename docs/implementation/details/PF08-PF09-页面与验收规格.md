# PF08 / PF09 页面与验收规格

## 2026-10-27 匿名明细服务端读取与耗时

开发环境大屏响应提供Server-Timing阶段耗时：链接读取、发布者身份/安全状态、根资源授权、源数据与可见行、目标授权/数据/响应组装、链接再检查和总计。只记录固定阶段名与毫秒，不输出主体、参数、凭据或SQL。首次跳转必须用未预取的行点击或清空页面内存后的完整明细请求复测；前端快照绘制速度、实例空选心跳和调试器暂停样本分别记录。

角色授权快照按集合读取角色事实，权限关联用单条EXISTS查询保留原软删除和启用条件。原生大屏可复用同次快照的活动角色元数据，但必须独立重读用户安全状态，核对租户、主体、删除、禁用和安全版本；缺少元数据的旧适配继续原目录读取。不得用快照元数据替代独立状态检查，也不得跨请求缓存权限。

一次明细请求中，根看板Run与Publish均保留检查；已验证的根资源和不可变修订交给内部导航解析继续检查可见行、参数映射和目标授权，避免重查同一资源。组装响应时仅复用与当前发布ID一致的已读修订，运行历史固定版时仍读取当前发布摘要。原链接末尾撤销/到期再检查不变。

## 2026-10-27 匿名明细短期预取

匿名页仅从当前实际显示的组件/行收集已配置导航候选，单页最多8项、并发2，预取完成的明细不递归加载。所有读取走原分享接口和完整授权，客户端不能指定任意目标或参数。局部内存最多10项/序列化8MiB，30秒或更短目标数据源读取周期内可用，禁止越过链接到期；离开来源页不得重置快照年龄，不落地或跨链接复用。

预取命中后立即显示已授权快照，同时立即复核服务端；预取中的请求只接续一次，未命中正常读取。返回恢复来源快照并复核，访问失败清空当前和缓冲，到期在复核等待中仍立即清屏，旧响应不得覆盖新页。主动/周期刷新及链接变化清理缓冲，卸载取消请求/定时器。验收分别记录命中绘制速度、未完成预取及冷路径，不将后台接口耗时与可见画面速度混为一谈。

## 2026-10-27 大屏链接再次复制与受授权约束的明细

链接窗口默认只列未撤销项，每个有效项可重复复制，撤销历史单独列时间且不提供操作；过期项不可复制。服务端不还原或存储原明文密钥，受保护凭据绑定同一原授权，旧密钥兼容、所有副本共用期限与撤销状态。返回凭据的响应不得缓存或写审计明文。

匿名大屏仅沿发布文档中的Dashboard规则下钻，逐级路径仅含规则及稳定行键，限制8级/8KiB；服务端从原授权的根看板重推目标、修订及参数，重新核查可见行、发布者和目标权限，不信任客户端目标/参数。导航元数据对外仅保留规则id/componentId/event。返回在同一匿名页恢复上一级，刷新/浏览器返回可重建路径；原授权撤销/到期/失权时根页与明细均清除。明细刷新遵守实例选择，发布修订变化返回全量。此范围不提供低代码/业务写入页匿名访问。

系统运行导航可在单次resolve返回已授权的目标运行数据，客户端一次性交接后即删除，限同一路由且5秒内有效，不持久化、不替代后续刷新授权，也不新增工作区标签管理封装。旧响应无运行数据时兼容正常GET。验收必须区分系统运行、匿名大屏和失效链路，记录实际请求次数与耗时，不能用渲染加载动画代替请求优化证据。

## 2026-10-27 运行明细返回工作区来源标签

系统内看板/轮播跳转时记录sourceTabId，采用工作区既有buildTabId身份。明细返回时仅匹配来源页面类型及资源编号一致的原标签，复用其完整route以激活原标签，不重新拼接query生成标签；同一资源的不同参数标签须准确区分。sourceTabId是导航元数据，禁止当作业务参数或授权依据。旧链接来源唯一时兼容激活；原标签已关闭或旧链接有歧义时才按保存的来源参数/修订/过滤/视口恢复页面，仍经过正常路由与运行授权检查。

## 2026-10-27 批次明细样例与行导航

运营总览的在制批次表使用稳定行键batch；行点击打开同一个批次明细看板，唯一业务参数batchNo来自Row.batch，不为每个批次建页面。明细展示该批次的基本信息、工序进度、执行记录、质量事项并保留返回上下文；合成样例无其他批次兜底，未知/缺少参数不可残留旧批次详情。设计器的Row字段选项相对于实际rows绑定集合，根数组和对象内集合都不得带集合索引前缀。示例内EnumMap为已登记绑定转换，用于合成样例配置；正式查询须通过有权限的参数化数据实例。匿名大屏导航另受分享合同约束，不因系统内目标可运行而扩大匿名访问范围。

## 2026-10-27 组件库数据分类移除（覆盖下节历史展示入口要求）

组件库只显示基础/图表/工业32类，DataSource、PageParameter、DataQuality不提供新增入口，后端目录和已有设计仍兼容。页面数据源、参数统一顶部管理；组件绑定选项将Instance明确显示为“页面共享数据源”。API配置区区分一份响应多组件共享和单组件独立请求，说明数据源登记/测试/启用、数据集配置/发布链路；具备studio.dataset.view权限时提供数据集管理跳转。验收覆盖7组件绑定同一汇总实例时一轮只调用1次，独立实例刷新互不误触发及真实数据集试运行。

## 2026-10-27 页面配置与画布展示入口区分

页面数据源和页面参数管理仅放在画布顶部，组件库下方不重复放配置入口。两者均使用AppFormDrawer保留模态/抽屉偏好，打开窗口不得增加画布组件。组件库DataSource名为“数据源信息”、PageParameter名为“参数值显示”，用于展示已有实例/参数；系统说明明确管理须从顶部进入。内部类型标识和已有绑定不改，用户自定义旧组件名称不批量重写；新加这两类组件的默认名称使用当前系统语言。验收检查顶部入口唯一、旧设计读写不变、参数编辑保存、双语名称以及原大屏运行兼容。

## 2026-10-27 看板来源与读取交互补充

画布工具栏设“页面数据源”，集中使用可切换模态/抽屉的AppFormDrawer；源选择器只编辑当前项，展示名称、引用组件，避免组件库或属性页堆长表单。来源分Dataset、Api、Constant；常量支持类型化值/列表与JSON，动态源展示秒为单位的读取/过期设置和可展开参数映射。组件数据来源区可选共享实例或“组件独立接口”，后者内嵌同一来源编辑器并仅选择接口Dataset；响应字段从既有Schema选择或填写路径。系统文案跟随语言，业务字段值不自动翻译。

“应用当前看板数据示例”只将现有Constant绑定转成页面实例：数值指标共享一个对象，列表/设备单独保持简短结构；布局、外观、当前值及已有动态绑定保持不变，可撤销，重复应用不重复建源，不自动保存或发布。设计/运行/轮播/独立大屏使用一致的按源周期：常量不轮询，0仅初次/手动，动态源1～86400秒且慢请求不重叠；瞬时错误保留上一份数据显示失败标记，权限/链接失效不得继续显示公共屏。

验收必须分别覆盖不同周期源不互相触发、共享源只读一次、缓存不吞掉实际查询、0/false/null/空列表、依赖乱序/循环、接口503/恢复、发布新版本及撤销链接。当前代码/隔离HTTP测试不代替用户调试浏览器实测；最新未测项见[PF-09证据](../../evidence/PF-09.md)。

版本：V1.4；2026-10-22。按用户最新要求：共用建模基础之外，低代码、看板、报表（含Excel）、追溯四部分分别开发和验收，客户按需选择模块。任务编号沿实施11/12，不新增阶段编号，不自动派遣。概念v7.7对齐修正见[复核记录](../../evidence/2026-10-21-platformstudio-concept-alignment.md)，新增B35～B45随各自部分验收，不推迟到整体集成。

每部分一条记录固定写`unit、sourceSnapshot(HEAD+WIP hash)、deploymentMode、installed/enabledModules、candidateLock、适用A/B/D编号、实际输入/请求/产物证据、通过/失败/待验/不适用、未覆盖原因、共享合同及下一写入者`。不得把未来用例标“不适用”后关闭整个研发任务；客户不购买某产品才可在该客户清单标不适用。分部机制验收、原生回归、外部MES适配机制及客户现场验收分别给结论，不新增一轮重复全测。

## 4. 看板线框与交互

表格列、序列、状态映射、图片列表、内容切换、管线路径、阈值/颜色区间、嵌入参数及常量行使用可视化/JSON双模式，支持增删排序，保留未知扩展、业务双语值及0/false/null；非法JSON不覆盖。表格/列表`props.rowHeight`可选16～200逻辑像素，`columns[].widthPercent`可选大于0且不超过100，已设置合计不超过100，未指定自动分配；列支持`align`。行高/列宽在共用渲染实际生效，无新字段的旧稿保持原显示。

数据绑定内部区分绑定字段（列/键/属性目标）与数据来源（实例/集合/各绑定取值来源）；字段项提供来源摘要及快捷定位。按来源类型显隐实例等输入，不因切换分类删除映射或改变设计文档。

系统属性名/绑定名/枚举标题随系统语言，存储键和值、用户文本及业务字段不翻译。通用外观默认可视化配置字体、字号、文字/背景/边框颜色、边框宽度、不透明度与内边距，保留JSON切换；双向同步保持未设置项、0和扩展字段，非法JSON/越界不覆盖原设置。fontKey由共用本地字体表渲染，未知键保持原有回退，不引入远程字体依赖。

右侧属性按基础/内容/外观/数据绑定/交互五类切换，分类固定可见，只滚动当前内容；绑定、导航规则按项展开，新建项自动展开。切换类别/组件保持模型编辑值，不将分类状态写入设计文件；字段输入、撤销、保存和发布合同保持一致。

设计画布与运行页共用组件渲染，实际逻辑尺寸、字体/配色、常量与预览实例绑定、图表/表格和工业图元一致；编辑时仅叠加选中/拖拽操作层。属性即时呈现，适应/100%只改变视口缩放，不改变保存画布。列表预热设计器代码；首屏先读取并显示当前草稿，再加载辅助目录，禁止默认示意图闪烁或旧请求覆盖新页。数据实例/参数变化使用现有草稿预览接口更新画布，拖动/样式变化不重新查询；缺必填参数或执行失败明确显示诊断，不伪造正常数据。

## 7. 通用操作细则与逐项验收

壳使用flex/grid及min-width/min-height:0，页面只占平台提供的可用空间，不套固定1920外壳。顶部标题/主按钮和编辑工具固定；结构/属性栏各自纵向滚动，中央只有一个viewport，不叠三层overflow。默认Fit模式无画布横竖滚动条；放大后用平移或中央滚动，不能让外页同步滚。

左右栏默认240/320px，宽度可拖（180..420/240..480）。≤1280优先收右栏为抽屉；≤1024左右栏互斥抽屉，收起按钮始终在工具栏。1366×768/1920×1080/1024×768验可操作；更窄运行页沿平台Mobile/PDA布局。设计功能可在触控宽屏操作，复杂画布提供展开工作区，不能声称PDA小屏有同等桌面编排效率；**部署/运行兼容范围不能缩减**。Mobile/PDA运行用相同授权与数据合同，桌面专用设计入口在窄端显示“展开设计工作区”而非丢失内容。

拖拽坐标=`(pointer - viewport原点 - pan)/zoom`；PointerCapture持续到pointerup/cancel，避免跨侧栏丢拖。一次拖动/批量对齐/删父带是一个历史命令，至少100步内存历史；undo/redo恢复模型、选择和属性，不撤销已成功的业务写入或发布。Ctrl+Z/Ctrl+Y只在设计器有焦点且非文本/IME输入时拦截；新的模型操作清redo。返回保存草稿后保留视口/选中状态，保存冲突先给比较/另存，不静默丢稿。

实际公共控件接线沿当前AppDataTable：`row-click`提供当前行，`activeRowKey`控制高亮，`selectedRowKey`控制单选，`selection-change`只用于真实选中业务；不要把点行跳转误实现为表格全局选择。Vue `h()`/`render()`表头控件使用`'onUpdate:modelValue'`，挂在父VNode外的控件显式同步本地值与回写；测试聚焦、真实日历选择、值保留和实际请求，不能只测手工emit或Mock控件。
