## 1. 范围与部署分支

| 部署形态 | 发布入口 | 正式使用入口 | 后端约束 |
| --- | --- | --- | --- |
| PlatformNative，原生导航适配已就绪且操作者有导航管理/发布权限 | 仅发布、发布并挂载菜单 | 平台业务菜单直接打开固定页面 NId 对应的运行页 | 通过 SystemData 公开应用端口定向修改关联节点；不批量发布其他草稿 |
| PlatformNative，导航不可用或缺导航权限 | 仅发布；显示菜单能力缺失原因 | 原有授权运行地址 | 不静默降级为另一套菜单 |
| ExternalMes/独立 Studio | 发布页面、打开独立展示 | 运行地址、`/screen/low-code/:nId` 全屏展示 | 不注册平台菜单；伪造挂载请求返回 `STUDIO_MENU_UNSUPPORTED` |

部署形态与身份来源分别处理；不以网址、前端构建名或是否存在菜单接口猜分支。API 返回部署形态及发布能力，UI 据此显示，服务端再次校验。独立全屏展示沿用身份及页面 Run 授权；不新增匿名业务写入链接，不复用看板匿名大屏密钥。Native 也可使用同一个授权全屏入口，但菜单发布仅属于 Native。

包含：发布到菜单、已有页面菜单挂载/解除、资源与菜单生命周期、在线 HTML/CSS/JS、链接嵌入、独立展示、真实验收样例。排除：通用审批、公式引擎、主从整单事务、任意后端脚本、业务 Excel 导入、远端 MES 自身页面修改，以及匿名低代码业务写入。

## 2. 生命周期与一致性

页面发布继续使用既有不可变修订和依赖门禁；菜单是页面稳定 NId 的入口，重新发布不创建第二个菜单。发布与导航分别有真实结果：UI 先完成页面发布，再挂载/同步菜单；失败显示“页面已发布，菜单处理失败”，提供单独重试，不重新发布页面。停用由运行授权实时过滤；原生删除在依赖/版本检查后先解除所属菜单，再提交页面软删除。菜单解除失败时保留页面并明确提示；菜单已解除但页面 CAS 失败时页面仍保留，入口不自动复活，刷新后可显式重新挂载。独立删除不调用平台菜单。

| 操作 | 页面 | 关联菜单 |
| --- | --- | --- |
| 首次选择发布并挂载 | 产生发布修订 | 按显式目录、名称、图标、排序创建稳定节点 |
| 重新发布 | 更新发布指向 | 沿用原节点，不覆盖菜单管理中尚未发布的名称/目录修改 |
| 停用 | 运行拒绝 | 正式入口隐藏，关联保留 |
| 再启用 | 通过既有准入后启用 | 恢复仍有关联且未被手工解除的入口 |
| 删除页面定义 | 依赖/版本检查通过后，先解除菜单，再提交软删除；解除失败则页面保留 | 只解除所属关联节点，保留父目录、其他菜单和业务记录；资源恢复不自动重挂 |
| 菜单管理中删除关联节点 | 页面和业务记录保持 | 解除关联；随后发布页面不得自动补回 |
| 恢复页面 | 沿用现有默认停用语义 | 不自动重新挂载，需操作者显式选择 |
| 打开的页面被停用/删除/撤权 | 隐藏业务内容和 iframe、停止后续页面操作，提示返回 | 导航刷新后同步消失 |

发布、挂载、同步和删除均验证租户、权限和版本。导航端使用稳定节点及控制面 CAS 版本拒绝迟到修改；页面重新发布不创建节点，菜单操作失败后单独刷新关联并重试。菜单确认框列出实际受影响的完整菜单路径，多个入口逐项列明。正常删除业务记录不改变页面定义及菜单。

## 3. 数据归属与兼容性（实现核对后收敛）

复用 SystemData 已有导航草稿、不可变发布快照及 CAS/审计/outbox 事务，不新增 Studio 菜单关联表，不追加无必要的 STU-010 迁移。页面代码和链接仍保存在既有资源草稿及不可变修订。菜单归属由已发布节点的可选 OwnedTarget={moduleNId,resourceNId,detached} 保存，三字段分别是模块稳定编号、Studio 页面稳定 NId、永久解除标记；仅受管链接有此对象。字段通过现有快照 NodesJson 持久化，不新增数据库列。旧节点不输出空 OwnedTarget，校验和与旧版完全一致。

所有受管链接复用一个声明过的 UIResource：studio.page.lowcode-runtime，路由 studio-lowcode-run，权限 studio.lowcode.run。运行投影补充 RouteParams={nId}，不重复注册每页平台资源。每页至多16个入口；菜单名称1～128、图标键128、排序0～100000；明确选择已发布PC Group，草稿目录不可选。

SystemData 公开 IOwnedNavigationService 定向挂载/解除，只提交当前节点及已发布快照中的该入口；其他草稿保留不发布。客户端携带控制面 ExpectedRevision；事务 CAS 拒绝迟到修改，冲突后刷新重新确认。挂载/编辑沿用稳定 NodeNId，页面重新发布不调用创建。手工删除和显式解除保留 detached 墓碑；普通导航发布、恢复草稿和回退不能清除墓碑，只有显式重新挂载可以恢复。正常菜单改名/移目录后仍按节点归属查找。

停用和撤权无需排队复制菜单状态：每次用户导航运行投影重新校验页面 Run、启用/删除/发布状态，排除不可运行入口，不缓存跨用户结果或仅凭导航版本返回304。资源删除前通过统一 IStudioPageLifecycle 定向解除全部关联；失败返回 STUDIO_MENU_SYNC_FAILED，页面未删除。页面提交 CAS 失败时已解除入口保持解除，可显式重新挂载。生命周期从发布服务统一执行，不只挂在 HTTP 路由上。关联状态直接读取导航事实及页面启用状态，不维护第二套同步表。恢复页面仍默认停用；解除标记不会自动清除。角色使用已有资源授权页，不在挂载中再实现一套角色授权。

## 4. 公共接口与权限

复用既有资源发布、状态、Grant、页面 Runtime、Dataset 和动作接口；菜单端口不跨模块写库。新增接口均在 `/api/v1/studio` 下：

| 接口 | 语义与参数 | 权限及错误 |
| --- | --- | --- |
| GET /pages/publication-capabilities | deploymentMode、canMountMenu、canOpenScreen、reasonCode | 已登录；Native 还核验导航适配/权限 |
| GET /pages/{nId}/menus | 关联列表、路径、解除标记、控制面版本及已发布父目录 | 页面 Design；可核对被手工解除的入口 |
| POST /pages/{nId}/menus | `{nodeNId?,parentNodeNId,label,iconKey,displayOrder,expectedRevision}`，已有 NodeNId 作显式编辑或重新挂载 | 页面 Publish 及 Native 导航管理/发布；最多 16 个关联 |
| DELETE /pages/{nId}/menus/{nodeNId}?expectedRevision=... | 解除该挂载，页面保留 | 页面 Publish 及导航权限 |
| GET /pages/{nId}/availability | 可用性、发布指向和原因；不返回代码、业务数据或秘密 | Run；撤权以 403/404 拒绝，停用/删除不可继续运行 |
| POST /pages/{nId}/custom-content | `{revisionNId?,draftVersion?,parameters}`；返回固定修订/精确草稿对应的嵌入链接，或30秒单次隔离文档票据及bridgeId | 正式 Run；草稿 Design + 精确草稿版本；no-store |

角色配置复用既有资源授权页及可信主体校验；菜单权限和页面 Run 授权取交集，菜单隐藏不代替 API 授权。Native SystemData 运行投影通过通用 scoped policy 过滤/补充节点 RouteParams={nId}；用户相关投影不得因仅导航 Revision 相同而返回错误的 304。前端菜单选择、快捷搜索和工作台身份同时携带 params/query，不把多页面合并成同一路由标签。

错误沿 StudioException：`STUDIO_MENU_UNSUPPORTED` 409、`STUDIO_MENU_UNAVAILABLE` 503、`STUDIO_MENU_SYNC_FAILED` 409、`STUDIO_VERSION_CONFLICT` 409、`STUDIO_FORBIDDEN` 403、`STUDIO_NOT_FOUND` 404、`STUDIO_CUSTOM_URL_FORBIDDEN` 422、`STUDIO_CUSTOM_CHANNEL_CLOSED`。无秘密堆栈进入 UI。

## 5. 自定义页面文档与运行

保留 Crud/Compose/Code 原值，新增 Html 和 Link；切换模式保留未启用的 HTML/链接配置，运行和条件校验只消费当前模式；Code 继续表示登记的代码页，不改造成任意脚本执行器。新旧 JSON 均使用 schemaVersion=1 的严格字段白名单，发布修订固定全部自定义配置。

```json
{
  "schemaVersion": 1,
  "mode": "Html",
  "parameters": [],
  "instances": [],
  "layout": {"id":"page-root","type":"Container","registryVersion":"1","props":{"columns":24,"gapPx":12},"children":[],"grid":{"span":24,"order":0,"minWidth":80}},
  "fields": [],
  "actions": [],
  "customHtml": {"html":"<button id=\"run\">查询</button>","css":"body{margin:16px}","js":"document.querySelector('#run').onclick=async()=>{console.log(await studio.query('batches'))}","formFields":[]}
}
```

Html：html UTF-8≤512KiB、css≤128KiB、js≤256KiB；允许完整 HTML 或片段，不对用户输入做破坏脚本语义的富文本净化。formFields 最多 64 个唯一稳定名称，只声明给登记动作 Form 映射使用的键；值仍由服务器执行现有类型、权限及动作 Schema 校验。编辑器复用已安装能力，首版可用等宽多行文本和 HTML/CSS/JS 页签，不为代码编辑引入大型依赖。

JS 必须实际可执行。内容从受控接口作为独立文档返回，使用 iframe sandbox=allow-scripts 和响应 CSP；不授予 same-origin，不读取父页 Cookie/Storage，不直接访问平台 DOM。内容先由授权 POST 准备，最多64份、总量16MiB、每份30秒；GET /pages/custom-content/{ticket} 只可消费一次并返回隔离 HTML，无业务API凭据。这样兼容Native Bearer和独立Cookie会话，脚本不接触平台令牌。默认 connect-src 'none'、form-action 'none'、base-uri 'none'、object-src 'none'、frame-src 'none'，图片仅 data:，不添加全站 unsafe-inline。脚本/样式内联仅限该隔离文档。内置 bootstrap 先于用户代码，提供 `studio.ready`、`studio.parameters`、`studio.query(instanceId,pageParameters?)`、`studio.executeAction(actionId,context)`；不能指定任意 URL、凭据或未登记动作。

桥接检查 iframe source、单次 bridgeId、消息方法/大小/请求 ID，限制同时请求数；父页只调用既有授权 Runtime/Dataset/动作端口。写动作沿现有 operationKey/回执处理 Unknown，重复请求不产生第二次写入。页面切换、iframe 再导航、重载、撤权和停用后关闭通道，拒绝迟到响应。标准参考：[HTML sandbox](https://html.spec.whatwg.org/multipage/iframe-embed-object.html#attr-iframe-sandbox)、[CSP sandbox](https://www.w3.org/TR/CSP3/#directive-sandbox)。

为避免 srcdoc 继承宿主页脚本策略导致“预览有外观、JS 不执行”，Html/Link 的未保存预览入口明确显示“保存并试运行”，保存草稿成功后请求精确版本隔离文档；保存失败保留代码且不打开旧预览。正式运行只用发布修订。预览写动作继续走模拟执行。

Link 文档增加 `embeddedPage={url,parameterMap:[{target,source}]}`；url≤4096，必须为部署 `AllowedFrameOrigins` 已登记的外部 HTTPS origin，不含用户名/密码，不允许 javascript/data/file。平台同源自定义内容不借链接模式取得 same-origin 权限。source 仅 PageParam/Constant，沿 Binding 空值规则；目标键唯一且≤64，服务器规范化和编码参数，不拼接未转义字符串，不由服务器抓取目标 URL。

Link 默认铺满运行区域，提供刷新及加载提示；目标服务器拒绝嵌入或未登录时给出实际接入说明，不绕过目标认证/CSP。15秒加载超时后恢复刷新按钮，允许用户重试，不永久卡在加载状态。参数映射替换URL中同名键，保留其他查询项与片段，最终URL限制16KiB。只对已登记外部 origin 授予 iframe 所需脚本/表单/同源能力；禁止父页导航和任意弹窗。链接配置删除或回退只影响 Studio 配置，远端页面与业务数据保留。

## 6. 页面组织与交互

```text
列表：名称 / 页面模式 / 发布与启用状态 / 菜单关联与全屏入口 / 操作
新建：名称、说明、CRUD / Compose / Code / 自定义HTML / 链接嵌入
设计：标题 + 模式/版本辅助文字                返回 / 撤销 / 试运行 / 保存 / 发布
可视模式：现有组件库 | 画布 | 属性/绑定/动作
Html：HTML / CSS / JavaScript 编辑页签 | 页面参数、数据实例、动作、可写 Form 字段
Link：URL、参数映射、已允许的目标域说明       | 预览区
发布 Native：仅发布 / 发布后挂菜单 → 目录、菜单名称、图标、排序；角色沿用资源授权
发布独立：发布说明 → 发布；成功后打开运行 / 独立全屏地址（无菜单选项）
菜单管理：实际关联路径、状态、重试 / 解除；删除页面确认列出受影响菜单
```

复用 AppPage、AppFormDrawer、AppDataTable、权限/语言/主题和当前设计器交互。标题模式与版本使用同一辅助说明样式；删除在属性右上角；返回成功后关闭原工作台标签。打开模式、菜单或参数配置不新增画布控件。

独立展示可交互，但仍按页面能力限制；停用/删除/撤权后移除 iframe 和业务内容。可用性检测可见页面每 5 秒、恢复前台立即复核；后端每次查询/动作仍重新鉴权，轮询不替代服务器检查。标准 CRUD 的页面来源请求携带 pageNId/revisionNId 并校验；不改变其他台账入口自身授权。
