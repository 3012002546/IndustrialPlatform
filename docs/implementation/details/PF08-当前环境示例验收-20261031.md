## 独立部署分支边界

当前运行的是 Native UnifiedHost；已验证同一发布页面的菜单入口与无外壳全屏入口。这里并没有额外启动一套 ExternalMes 独立部署。

独立部署使用其自身站点域名及 `/screen/low-code/<页面编号>`，页面必须在该部署中创建/导入、发布，并使用该部署的身份与资源授权；当前原生数据库的编号不会自动成为独立部署资源。ExternalMes 不提供“发布后挂载到菜单”及平台菜单关联，后端也拒绝菜单挂载请求。不能仅去掉平台外壳就称为独立部署验收通过。
