# 12-.NET10 Clean Architecture模板设计

> 文档版本：v1.0
> 项目名称：Industrial Platform
> 文档类型：.NET 10 微服务基础模板规范
> 目标：建立所有业务服务统一开发模板
> 适用范围：
>
> * Identity Service
> * ReferenceData Service
> * MasterData Service
> * OperationalData Service
> * WorkOrder Service
> * Weighting Service
> * IoT Collector Service
> * Trace Service
> * Batch Record Service

---

# 1. 文档目的

Industrial Platform采用：

```
DDD
+
Clean Architecture
+
CQRS
+
Domain Event
+
Event Driven
+
Microservice
```

因此所有微服务必须遵循统一模板。

目标：

* 降低新增服务成本
* 保证代码结构一致
* 方便Codex自动生成
* 方便后期团队扩展
* 保证领域边界清晰

# 5. Entity设计规范

基础：

```csharp
public abstract class Entity<T>
{

    public T Id { get; protected set; }


    protected Entity()
    {

    }


}
```

---

业务实体：

```csharp
public class WorkOrder
    : AggregateRoot<Guid>
{


    public string OrderNo {get;private set;}


    public WorkOrder(
        string orderNo)
    {

        OrderNo = orderNo;

    }


}
```

# 12. Result统一返回模型

所有API：

禁止：

```csharp
return Ok(data);
```

统一：

```csharp
Result<T>
```

---

定义：

```csharp
public class Result<T>
{

    public bool Success {get;set;}


    public string Message {get;set;}


    public T Data {get;set;}

}
```

---

返回：

```json
{
 "success":true,
 "message":"success",
 "data":{}
}
```
