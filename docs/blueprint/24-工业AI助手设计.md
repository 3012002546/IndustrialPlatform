PF10A先兼容平台项目/用户范围、File、知识/问题闭环与受控Dataset，再为同核心定义独立部署/外部MES嵌入。知识/问题核心和助手/模型/索引的依赖分别声明；关闭助手不阻断基本问题/知识管理，不强制装ServerMonitor。当前范围及未决闭环服从[蓝图32§2.1～2.2、§5](32-Industrial%20Platform%20Service%20Host与内部模块边界.md)，派遣前仍须完成实施13A细化，本文远期AI方向不自动转为当前任务。

> Industrial Platform 工业数字化执行平台
> KnowledgeHub 内知识/问题与助手设计输入；远期工业AI方案另列

版本：V1.0
定位：KnowledgeHub／知识中心以知识库为核心，问题与AI助手为主要能力；工具与监控为辅助，工业决策/自动执行为远期方向

## 当前范围与阅读规则（2026-11-17）

产品/宿主统一命名KnowledgeHub／知识中心／KnowledgeHub.Service，内部知识内容治理模块仍叫KnowledgeBase。知识搜索、分类、最近更新和AI问答是主要页面入口；JSON解析/格式化、二维码/条形码、内部HTTP/API调试属于辅助工具，其输入输出、权限及线框按蓝图32§5.5先细化。PF10参考独立维护的ServerOpsCenter，按平台现场内网部署设计，不依赖VPN或旧系统，PF10A先建宿主、PF10后置，监控闭环目标保留；方向确认不代表已实现或已可派遣。

当前权威边界为蓝图32§2.3、§5，不另建AIAssistant.Service，也不依赖ServerMonitor运行。[实施13A](../implementation/13A-Industrial%20Platform知识中心开发实施方案.md)已有核心设计稿，完整字典/接口/页面仍待细化，以下历史实体/DDL/API示例不得直接作为派遣合同。

首期优先服务内部实施、运维知识和问题处理（2026-11-17用户确认）；生产API/MCP尚未提供，不把下文生产Agent示例当作当前真实统计能力或首期业务前置。

| 模块 | 当前边界 |
| --- | --- |
| KnowledgeBase | 知识/修订/自动入库及索引事实的所有者；问题解决方案由人工转草稿，不由助手直接发布 |
| IssueTracking | 问题登记至关闭；完整状态、分派、附件、验证和审计仍待确认 |
| KnowledgeAssistant | 仅检索当前项目/用户有权访问的已发布知识，显示引用与适用版本，不拥有第二套知识主档 |
| DataAssistant | 首期只对受控Dataset/只读视图生成结构化查询计划；行列授权、预览、导出与审计由受控执行链落实 |
| ProjectWorkspace | 客户/工厂实施项目的知识与数据权限作用域，不做工时/预算/项目排程 |
| ModelGateway | 首期先接DeepSeek官方API，本地模型暂缓；项目配置启用，未配置项目关闭。Chat与Embedding分别选型。关闭助手不阻断基础问题/知识管理 |

2026-11-18 用户确认全局助手是平台操作入口。平台原生行为操作平台数据和页面。独立接入既有 MES 时按项目重新登记业务语义、权限、执行方与成功条件，两种模式复用发现、执行和回执过程。已有行为可接入新对象，新行为由模块提供处理器。后端查询由业务服务执行，页面动作由发起标签页领取和回执。模型接入以 DeepSeek Responses API 文档为准。[行为注册](../implementation/details/PF10A-全局助手与资料复用.md) · [前端执行与回执](../implementation/details/PF10A-核心接口与页面规格.md#44-页面动作与回执)

以下§1～2为远期背景；§5～18的旧模型、工业Agent、存储和接口为候选设计素材；§19及§22～23是远期场景。生产写操作、自动发起MES动作、自由SQL和通用Agent执行端点不进入PF10A首期。受限Text-to-SQL属于后续另行设计范围。当前问题→知识→检索的设计缺口按蓝图32§5.4保留，不能用历史AI示例替代。

## 1.1 背景

传统MES系统解决：

* 生产执行
* 工单管理
* 物料追踪
* 设备采集

### 数据问题


传统MES需要工程师：

耗时几十分钟甚至数小时。

# 18. 工业AI安全设计

必须考虑：

## 权限控制

AI不能越权。

例如：

普通员工：

```
只能查询自己产线
```

管理员：

```
仅查询其明确获授权的租户、项目、知识和Dataset范围
```

系统配置管理权限不自动等于全部业务数据读取权，也不能使知识助手检索未发布草稿或其他项目内容。助手的有效权限遵循当前身份、项目和行列授权；可靠引用不足时明确说明，不能用空sources冒充已有知识依据。
