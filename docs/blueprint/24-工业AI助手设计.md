# 1. 工业AI助手定位

## 1.1 背景

传统MES系统解决：

* 生产执行
* 工单管理
* 物料追踪
* 设备采集
* 质量管理
* 批记录

但是实际工业现场存在大量问题：

### 数据问题

例如：

```
为什么今天产线OEE下降？

为什么设备频繁报警？

为什么某批次质量异常？

为什么某物料消耗超标？

为什么某工单延期？
```

传统MES需要工程师：

```
查询数据库
查看报表
分析趋势
检查日志
询问设备工程师
```

耗时几十分钟甚至数小时。

---

## 1.2 Industrial AI Assistant目标

Industrial AI Assistant：

不是聊天机器人。

而是：

> 面向工业现场的AI数字工程师。

目标：

```

 |

 |

 |

 |

 |
```

提供：

1. 工业知识问答
2. MES数据分析
3. 异常诊断
4. 工艺辅助
5. 设备预测分析
6. 自动生成报告
7. 自动执行部分业务操作

# 8. Agent详细设计

# 8.1 生产分析Agent

职责：

能力：

查询：

```

```

示例：

用户：

> 为什么3号产线今天产量下降？

Agent流程：

```
理解问题

↓

调用Production Tool

↓

查询WorkOrder

↓

查询IoT数据

↓

查询OEE

↓

生成分析结果

```

输出：

```
原因：

1.
设备停机45分钟

2.
换型时间增加20%

3.
人员调整导致效率下降


建议：

优化换型计划
```
