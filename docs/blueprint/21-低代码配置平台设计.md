# 1. 平台定位

Industrial Platform 不希望成为：

> 每个客户重新开发一套MES系统

而是建设：

> 面向工业场景的低代码配置平台

目标：

通过配置实现：

* 工厂建模
* 工艺流程配置
* 页面生成
* 数据模型扩展
* 表单设计
* 审批流程
* 设备点位配置
* 报表设计
* 业务规则配置

最终：

```text
传统MES开发模式


需求
 |
设计
 |
编码
 |
部署
 |
修改


        ↓


Industrial Platform模式


需求

 |

配置


 |

发布


 |

运行

```

# 7. 核心领域模型

# 7.1 ApplicationDefinition

应用定义。

例如：

```
MES

称量系统

设备管理

```

模型：

```csharp
public class ApplicationDefinition
{

Guid Id;


string Code;


string Name;


string Version;


ApplicationStatus Status;


}

```

---

# 7.2 EntityDefinition

动态业务实体。

例如：

创建：

```
InspectionRecord
```

模型：

```csharp
public class EntityDefinition
{

Guid Id;


string EntityName;


string DisplayName;


List<FieldDefinition> Fields;


}

```

---

# 7.3 FieldDefinition

字段定义。

```csharp
public class FieldDefinition
{

string Name;


string DataType;


bool Required;


string DefaultValue;


}

```

支持：

```
string

int

decimal

datetime

bool

enum

reference

```

---

# 7.4 PageDefinition

页面定义。

```csharp

string JsonSchema;


}

```

页面布局JSON。
